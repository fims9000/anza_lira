# Scientific validation

comparison with V1, deformable convolution, orientation prediction, and clDice.
Confirm that the controlled benchmark tested generator-defined branch identity,
that its frozen negative result was preserved, and that no test result affected
architecture, threshold, split, or trace settings.

Keep CRACKS Settings A, B, and C distinct. Verify expert-lock receipts for
Setting A and pre-test selection receipts for every B/C fold. Human claims must
refer only to agreement with the available expert annotation. Permit only the
local determinant-one hyperbolic analogy, never Anosov or ergodicity claims.
Every numeric report claim must resolve through THESIS_NUMBERS.json to a frozen
machine artifact.
