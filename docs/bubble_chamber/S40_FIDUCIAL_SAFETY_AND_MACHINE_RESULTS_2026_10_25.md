# S40 — автоматическое выявление реперных крестов в H50Z и отказ от опасных стыков

**Дата:** 25 октября 2026. **Ветка:** `research/bubble-chamber-graph-lira`. Датасет не размечался пользователем и экспертная разметка не создавалась. Работа выполнена на реальных пикселях двух H50Z BMP и исходных метках реперов, предоставленных вместе с архивом.

## Научный вопрос

Почему S39 даёт много похожих на треки линий? Можно ли автоматически установить хотя бы один класс заведомо посторонних структур и исключить его из безусловных графовых стыков, сохранив все исходные пиксели и гипотезы?

Согласно *Руководству пользователя по работе с программой visualMetro* (Беляев, Бушмина, Клевцова, 2025), реперные кресты служат геометрической калибровке измерений стереофотографий. Источник `labels.json` для H50Z содержит метки `f1`–`f8` и отдельно `start`. **Крест не равен физическому треку, а `start` не считается отрицательной разметкой.**

## Метод

1. Из подтверждённого исходного файла `labels.json` загружаются координаты **7** крестов на фотографии 005 и **8** на 006. Координаты остаются строго приватными. Метки вне кадра, дубль ID и отсутствие крестов вызывают ошибку, а не молчаливую коррекцию.
2. Вырезается квадрат 512×512 вокруг каждого креста из подлинной 8-битной BMP. Автоматический Hough-преобразователь по границам ищет **две независимые оси X**, действительно проходящие через указанный центр. Направления рассчитываются из изображения, а не задаются вручную.
3. На каждой исходной машинной полилинии из S39 вычисляется расстояние до зоны репера. Отдельно проверяется, проходит ли ≥60% её точек вдоль одной найденной диагональной оси, в пределах 9 px и отрезка ±220 px. Этот критерий — только признак сходства с калибровочной меткой, не сертификат класса фон/частица.
4. Проверяются все **567** исходных предложений в 39 целевых фрагментах, **1166** предложений из 128 пространственно выбранных фрагментов полных BMP, а также **511 узлов и 182 ребра** графа S39. Для ребра анализируются оба исходных узла и предложенная геометрия мостика (Hermite spline). Источник остаётся неизменным; сомнительным ребрам ставится `FIDUCIAL_RISK_ABSTAIN`.

## Проверенные результаты, не спутать с точностью распознавания частиц

| Показатель | Результат |
|---|---:|
| Меток реперных крестов в исходных материалах | 15 (005: 7, 006: 8) |
| Крестов, где найдено две независимые оси X | 15 / 15 |
| Машинных линий в 15 служебных 512×512 фрагментах | 143 |
| Помечено как близкие/похожие на репер среди них | 75 / 143 |
| В целевых 39 фрагментах S39: только близкие к центру | 35 / 567 |
| В целевых 39 фрагментах S39: похожие на диагонали | 51 / 567 |
| В 39 фрагментах: объединённый риск (без повторного счёта) | 56 / 567 |
| На 128 дополнительно выбранных фрагментах: риск | 12 / 1166 |
| В S39-графе: узлы с риском | 56 / 511 |
| В S39-графе: ребра с риском | **43 / 182** |
| Ранее названные геометрически однозначными ребра, теперь с риском | **5 / 70** |
| Физически подтверждённые объединения | **0** |

**Ключевая интерпретация:** реперные кресты с двумя длинными диагоналями действительно являются значительным источником тёмных машинных линий. Отслеживание двух длинных лучей оказалось полезнее ограничения только окрестностью центра. Но нельзя автоматически выбрасывать всё, что пересекает репер: настоящий трек может наложиться на этот участок, поэтому применяется **признак риска и воздержание**, а не деструктивное удаление.

**Эти 56/567 и 43/182 нельзя интерпретировать как измеренную ложноположительную долю по всем физическим событиям.** Это найденные кандидаты, потенциально связанные только с известными служебными объектами. Остальные кандидаты также не подтверждены.

## Демо для физиков

Закрытый ZIP `ANZA_LIRA_S40_PRIVATE_MACHINE_DEMO.zip` объединяет галерею S39 (39 целевых фрагментов, 128 дополнительных участков, графы) и новую **S40-галерею 15 реперов**. Никаких действий по ручной разметке от пользователя не требуется. Распаковать полностью, открыть корневой `index.html`, выбрать S39 или S40. Красные линии — машинные гипотезы, совпадающие с X-репером; бирюзовые — другие линии, жёлтая окружность — зона неопределённости, сиреневые направляющие — машинно восстановленные оси. Галерея использует исходные реальные пиксели H50Z и поэтому архив должен оставаться приватным.

Число файлов и PNG в ZIP контролируется, ZIP CRC пройден, Chromium QA через встроенные PNG (из-за блокировки `file://` в тестовой среде) — **15/15 изображений** отображены, ошибок JavaScript нет. SHA-256 пакета: `301804cdcbb1c0424a6edcdd798d66808033189298e5acda2fd512480fdc2ab2`.

**Смысл результата:** S40 уже автоматизировал один физически понятный источник ложных треков, не используя пользовательскую разметку. Чтобы улучшить алгоритм дальше, нужно машинно проверять устойчивость детектора к экспозиции, локальному засвету, другим дефектам сканирования и сложным пересечениям на заранее зафиксированных сценах. Для независимой валидации физических частиц в будущем всё ещё нужны зарегистрированные 3-проекционные кадры и подтверждённые исходные измерения; текущая демонстрация не выполняет 3D, массы или particle-ID.
