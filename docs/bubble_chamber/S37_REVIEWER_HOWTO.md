# S37. Как проверять настоящие H50Z-фрагменты (приватно)

Этот документ НЕ содержит оригинальных фотопикселей или операторских координат.

1. Скачайте **отдельно** приватный архив `S37_PRIVATE_OFFLINE_REVIEWER.zip` (он не должен попасть в публичный GitHub). Распакуйте целиком, откройте `S37_REVIEWER/index.html` на локальном компьютере; не копируйте только HTML, поскольку изображения лежат в соседнем каталоге `crops/`.
2. Интерфейс показывает два предлагаемых фрагмента: зелёный и оранжевый. Серые линии — остальные неподтверждённые машинные кандидаты. Для каждого предложения `same / different / unsure` фиксируйте исключительно **локальное предварительное** мнение. При сомнении нажимайте `unsure`. Дополнительно проверьте отдельные линии через `Accept / Reject / Unsure`.
3. Быстрые клавиши: `1` — same, `2` — different, `3` — unsure, стрелки — навигация. Используйте `Next unreviewed`, чтобы не терять очередь.
4. Нажмите `Export S31-compatible corrections JSON` перед закрытием браузера. Проверьте наличие `S31_machine_labels_local_corrections.json`; архив и JSON хранить только приватно. Интерфейс не сохраняет ответы на сервере.
5. Для проверки структуры и исходного происхождения запускайте из корня **ветки** `research/bubble-chamber-graph-lira`:

```bash
python scripts/research/bubble_chamber/s37_validate_local_corrections.py \
  --private-source-zip /private/S35_ANZA_FRAGMENT_LINK_RESEARCH_PRIVATE.zip \
  --corrections /private/S31_machine_labels_local_corrections.json \
  --aggregate-report /private/S37_REVIEW_COUNTS.json
```

Статусы `LOCAL_SAME_PROVISIONAL` и `LOCAL_DIFFERENT_PROVISIONAL` не являются физически сертифицированной истиной. Для публикации метрик на реальных треках необходима отдельная независимая разметка квалифицированным физиком с указанием фильма, запуска, камеры и контура, а также подтверждённые отрицательные пары; всё остальное остаётся UNKNOWN. Ни один ответ из HTML автоматически не разрешает восстанавливать 3D-событие, импульс, заряд или тип частицы.

Новый лёгкий разметчик сохраняет исходные пиксели и показывает готовые кандидаты. Для **ручной правки координат** кривых используйте более полный старый приватный HTML из S35; лёгкая версия такого редактора не содержит.
