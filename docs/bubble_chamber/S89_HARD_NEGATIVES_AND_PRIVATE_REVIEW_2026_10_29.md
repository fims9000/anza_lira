# S89 — контроль ложных срабатываний и приватный аудит фотографий пузырьковой камеры

Дата: 29 октября 2026 г. Ветка: **только** `research/bubble-chamber-graph-lira`.

## Что выяснилось

S88 сильно улучшал покрытие *несложных искусственно нарисованных* осевых линий: 99.9% при выбранном на CAL бюджете 1.5% пикселей, но на отдельном более тяжёлом генераторе это преимущество **не переносится автоматически**. Цифры из S88 не были метриками настоящих H50Z треков. Новый эксперимент S89 использует S88 CAL-пороги `low_snr=0.816`, `high_snr=1.7` **без** донастройки на новом TEST.

Источник численных результатов: `S89_GENERATED_ONLY_ARTIFACT_STRESS_2026_10_29.json`. Пять условий, **6 независимых сгенерированных сцен на условие** (всего 30), начальные seed 9000, 9300, 9600, 9900, 10200. Ни H50Z, ни visualMetro, ни реальные координаты не участвовали.

| Генерируемый сценарий | S88: доля покрытых осевых точек (±2 px) | Только диагностический «консенсус» | S88: доля пикселей-кандидатов **вдали** от синтетических осей (более 3 px) |
|---|---:|---:|---:|
| Слабые кривые + зерно | 4.59% | 3.57% | 0.416% |
| Размытые слабые кривые | 89.55% | 33.83% | 0.735% |
| Кривые и пересекающие царапины | 46.50% | 23.87% | 0.843% |
| Только царапины | **осей нет** | **осей нет** | **1.667% всех пикселей — ложные для данного синтетического сценария** |
| Только фидуциальные кресты / прочие артефакты | **осей нет** | **осей нет** | **0.463% пикселей — ложные для данного синтетического сценария** |

Сценарии «только царапины» и «только фидуциалы» могут содержать другие процедурные дефекты и зерно. Они не эквивалентны реальной физической плёнке. Сценарии «кривые» тоже содержат искусственные нерелевантные дефекты. Метрика ±2 px — покрытие нарисованных осевых пикселей, **не** precision/recall реальных частиц. При отсутствии осевой GT метрика recall намеренно `null`, а не 0/100%.

### Важный отрицательный результат

Идея «оставить только пиксели, переживающие небольшое размытие и дополнительное зерно» на этих синтетических сценах **серьёзно снижает полноту**: для размытых кривых 89.5 → 33.8%. Царапины и кресты при этом тоже иногда стабильны. Поэтому никакого включения такого фильтра в S86/S88, отбрасывания фрагментов или физического автоматического объединения в S89 **нет**.

## Что теперь умеет S89 на реальных собственных BMP

S89 читает **уже сформированный приватный S86 каталог** и оригинальный 8-битный BMP, сверяет SHA-256 оригинала с provenance S86, валидирует каждый тайл и mask SHA-256 в замороженном S86, проверяет, что запущен именно `s88-steerable`. Затем выбирает 16 (по умолчанию) исходных тайлов по квантилям плотности машинных кандидатов: от почти пустых к насыщенным. Позиции и физические метки в выборку не подмешиваются.

Для каждого машинного фрагмента в этих тайлах S89 измеряет **в пространстве изображения**:

1. медианную разницу яркости центра и соседних отсчётов по обе стороны поперёк локальной касательной (серые уровни; **не** `dE/dx`);
2. долю уже наблюдаемой линии, поддержанную детектором при дополнительном небольшом blur и зерне, с неизменёнными порогами S88;
3. геометрическую прямизну (прямая частица тоже может быть настоящей) и признак касания границы тайла;
4. флаги `PERTURBATION_UNSTABLE_REVIEW`, `LOW_TRANSVERSE_DARKNESS_REVIEW`, `STRAIGHT_IMAGE_LINE_AMBIGUOUS_REVIEW`, `TILE_EDGE_CONTINUATION_UNKNOWN`.

Отсутствие флагов не доказывает реальность трека. Наличие флагов не доказывает царапину или брак. Приоритет `REVIEW_FIRST` — только порядок просмотра в приватной галерее, **не класс или вероятность**. Все фрагменты остаются **UNKNOWN**, исходная S86 маска и координаты остаются без изменений.

### Воспроизводимый запуск (на машине, где лежат исходные PRIVATE BMP)

1. S86/S88 — один исходный BMP, весь кадр по неперекрывающимся ядрам с halo. Порог из замороженной S88-CAL, не порог по физическим GT:

```bash
python scripts/research/bubble_chamber/physicists_full_bmp_segmentation.py \
  --bmp /PRIVATE/H50Z/H50Z_030_01_005.bmp \
  --private-out-dir /PRIVATE/results/H50Z_005_S86_S88 \
  --method s88-steerable --s88-low-snr 0.816 --s88-high-snr 1.7 \
  --core 384 --halo 48 --preview-limit 12 --resume
```

Для первого запуска на **новом пустом** выходном каталоге уберите `--resume`. При повторном запуске на прежнем каталоге укажите его явно. S86/S88 может считать полный H50Z долго; сохраняет состояние по тайлам. Это **не** способ запуска со случайным неаттестованным checkpoint.

2. S89 — **не обучает** и не сдвигает порог, только исследует исходные кандидаты:

```bash
python scripts/research/bubble_chamber/physicists_s89_audit.py \
  --s86-dir /PRIVATE/results/H50Z_005_S86_S88 \
  --bmp /PRIVATE/H50Z/H50Z_030_01_005.bmp \
  --private-out-dir /PRIVATE/results/H50Z_005_S89_AUDIT \
  --max-tiles 16 --preview-tiles 12
```

Откройте в браузере `/PRIVATE/results/H50Z_005_S89_AUDIT/index.html`. Здесь находятся **настоящие пиксели**, если запуск был на подлинном BMP; галерею, журнал координат, BMP и модели **никогда не публикуйте** в GitHub.

Приватные выходы S89: `candidate_audit.ndjson` (по фрагментам), `sampled_tiles.ndjson` (по тайлам), `report.json`, `index.html`, `preview/*_gray.png`, `preview/*_diagnostics.png`.

### Ограничения, важные для физиков

- Доступные H50Z фотографии `005`/`006` относятся к **одному физическому запуску**, а их `labels.json` содержит **операторские и фидуциальные точки**, не полную маску треков. Никаких новых физических GT по ним в S89 нет. Файл 070 visualMetro — **другой источник**; совпадение координат не доказывает соответствие.
- Здесь **нет** определения направления частиц, массы, импульса, заряда, `dE/dx`, stereo matching или 3D реконструкции. Не используйте измеренные пиксельные характеристики как ионизацию без физической/оптической калибровки.
- Артефакты, проходящие проверку стабильности, **не исчезают**. Полнота при новом контрасте может быть намного хуже, чем на раннем синтетическом протоколе. Нужен фактический аудит исходных изображений и контроль ложных срабатываний.
- Этот этап *не* повышает accuracy детектора: он обнаруживает обобщающие провалы и даёт приватный интерфейс для анализа. **S72/S85 и исходные S86/S88 маски не меняются.**
- Уровень готовности: приватная инструментальная диагностика для предварительного просмотра, **не** автономный детектор физических треков и не validation на нативных H50Z.

### Следующий эксперимент

Исследовать физически осмысленные локальные признаки пузырьковой структуры (точечность, толщина, концентрация контраста, пространственное постоянство), не выдавая эвристики за метки частиц. Перед заявлением улучшения — независимые реальные данные по различным плёнкам и несколько экспертно проверенных «track/artifact/unknown» и «same/different/unknown» с сохранением неизменного TEST. Массовая ручная разметка пользователем не требуется.
