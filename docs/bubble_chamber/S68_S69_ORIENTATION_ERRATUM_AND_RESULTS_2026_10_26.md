# S68-S69: исправление оценки синтетических соединений (2026-10-26)

**Статус:** independent fresh synthetic test завершен; опыт не доказывает распознавание физических частиц, автоматическая физическая склейка запрещена.

## Дефект оценки, выявленный в S69

В генераторе S56 каждый искусственный фрагмент может иметь перевернутый порядок точек. Исторический оценщик S64 принимал фиксированный индекс конца за исходное направление. Тест: две правильные пары после разворота среднего исходного фрагмента ошибочно оцениваются как две неправильные. Новый модуль bubble_chamber/s69_orientation_invariant_audit.py после окончания pixel-only инференса использует истинные искусственные пары и выбирает ближайшие взаимные концы, не предполагая направление записи. Старые отчеты S64-S68 нельзя сравнивать с исправленными без перерасчета.

**Точное воспроизведение:** 4 архивных seed S68 × 4 варианта; все старые агрегаты совпали. На одних и тех же 96 сценах после исправления только оценщика правильные соединения: S39 11→41, S67 11→40, S68 branch split 10→39, S68 refine 10→39.

## Новый S69 TEST

96 совершенно новых синтетических сцен, 384 искусственных правильных связи и 192 потенциальные трехчастные цепочки. На фоне 39 закрытых тайлов двух фотографий H50Z одного запуска рисуются искусственные траектории из настоящих измеренных форм visualMetro пленки 070. 79/30/36 полных кадров визуальных измерений для train/CAL/test; измерения 070 НЕ являются GT фотографий H50Z.

| Арм | Правильных искусственных стыков | Прочих предложенных | Сцен хотя бы с одним неверным | Полных искусственных цепочек |
|---|---:|---:|---:|---:|
| S39 | 59 | 46 | 35 | 18 |
| S67 crossing stitch | 58 | 40 | 32 | 18 |
| S68 branch split | 56 | 42 | 28 | 17 |
| S68 branch refine | 59 | 37 | 28 | 19 |

По направлениям: 005→006 S39 33 правильных / 31 прочих / 10 цепочек, S68 refined 34 / 24 / 10; исправленный CAL выбрал S39. В обратном 006→005 S39 26 / 15 / 8, S68 refined 25 / 13 / 9; исправленный CAL выбрал refined, но независимый тест потерял один правильный стык. Следовательно, предварительно зафиксированный deployment gate не выполнен, S39 остается основным.

Непараметрический парный bootstrap по полным искусственным сценам (1200 повторов) дает для дельты правильных стыков S68-refine − S39 в четырех seed 95% интервалы на сцену: [-0.208;0.083], [-0.125;0.333], [-0.208;0], [0;0.125]. Устойчивого доказательства выигрыша нет.

## Научные оговорки / данные

- Ни для одного настоящего фрагмента H50Z нет подтвержденной физической идентичности: native expert GT = 0.
- Два фото H50Z из одного run, без полного независимого физического holdout или трехпроекционного подтверждения.
- Метки в S69 — только искусственные. Истинная ориентация/масса/3D траектория частиц здесь не оцениваются.
- Исходные архитектуры AZUNet/U-Net и S39 были оставлены без изменений; S68 не внедрен.
- В Git не включаются BMP/7z, измеренные координаты и кадровые IDs, закрытые псевдоразметки, веса, per-scene детали.
- Оценщик S69 используется ТОЛЬКО после pixel-only inference; никакой информации от генератора в прогноз не попадает.
