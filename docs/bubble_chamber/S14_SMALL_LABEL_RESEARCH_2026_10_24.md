# S14 — Малый объём разметки, ANZA + Graph-LIRA для пузырьковых камер

**Новая цель:** физик размечает ограниченный стартовый набор и отдельные сложные примеры; затем алгоритм на новых снимках сам выделяет линии, группирует фрагменты в отдельные треки и предоставляет измерения, не требуя постоянной ручной обводки. Неподтверждённые физически выводы остаются недоступны/отмечены неопределёнными.

## Рекомендуемая архитектура

1. **Пиксельный модуль ANZA**: оригинальный `AZUNet` на реальных BMP-фрагментах. Обучение только по проверенным экспертным меткам 1=линия заряженной частицы, 0=подтверждённый артефакт, 255=неизвестно. Неизвестные пиксели НЕ фон.
2. **Уменьшение требований к разметке:** частичные линии (scribbles), подтверждённые отрицательные примеры, интенсивное использование неразмеченных кадров. Непрерывная EMA teacher/student consistency только в обучающей группе; два согласованных и уверенных teacher-предсказания могут получить МАЛЫЙ вес как псевдообучение, но никогда не переписывают решение эксперта и не участвуют в оценке качества.
3. **Graph-LIRA как модуль принадлежности треков:** вершины — наблюдаемые сегменты с направлением, кривизной, полутоном/шириной; рёбра — возможные соединения концов. Первые метки — простые вопросы эксперту `один трек / разные треки / неопределённо`. Требования: непротиворечивость связей, запрет повторного использования концов, исключение циклов, отказ от сомнительных соединений. В дальнейшем подключить обученные признаки ANZA, **но сравнить с обычной свёрткой** — прошлый S13 не подтвердил прирост от ANZA.
4. **Геометрия и физика:** получаем отдельные двумерные контуры, начальные и конечные точки и коэффициенты аппроксимирующей кривой. Трёхмерная реконструкция, импульс и физическая идентификация только после настоящей геометрической, магнитной и стереокалибровки.

## Сколько разметки минимально нужно

Для первого пилота предложен **не гарантированный минимум**, а следующий масштаб работ: выбрать разнообразные исходные изображения из нескольких независимых запусков, разметить 10–30 небольших фрагментов (подтверждённые позитивные линии и подтверждённые артефакты), а также проверить 40–160 сомнительных пар фрагментов. Дополнительные 100–300 решений можно собирать активным выбором сложных случаев вместо случайного просмотра целых фотографий. Обязательны отдельные данные для выбора порога и независимой итоговой проверки; для пропана/водорода тест проводится отдельно.

Это **две разные разметки**, и заменить одну другой нельзя: 2D маска учит находить линию, а метка пары учит связывать две линии в одну частицу.

## Что реально проверено S14 (в пределах доступного архива)

Реальная сторона данных: 145 корректных кадров одной плёнки 070, 1 073 экспертных трека и 17 321 пространственная точка. Сформированы случаи искусственного пропуска двух экспертных измерений. Визуальные пиксели здесь не использовались, поэтому проверялись лишь признаки геометрической связи, не сегментация AZConv.

Протокол: 94 обучающих кадров, 26 калибровочных и 25 тестовых (разделение по целому кадру). На 3 разделениях с разными seed обучающие метки пар искусственно раскрывались порциями: 20/40/80/160/320/640. Валидационный порог подбирался с ограничением FPR по кандидатам 1%, решения ограничивались mutual-top1 и margin=0.05. Тест не участвовал в выборе кадров для разметки или порога.

| Решений о парах | Случайный отбор, axial proxy (mean recall) | Активный отбор, axial proxy (mean recall) |
|---:|---:|---:|
| 20 | 15.5% | 15.5% |
| 40 | 27.8% | 48.8% |
| 80 | 35.4% | 63.6% |
| 160 | 50.6% | 73.0% |
| 320 | 62.2% | 85.5% |
| 640 | 72.5% | 89.2% |

При 320 решениях у axial proxy с активным отбором в трёх тестах было **1, 3 и 0** ложных соединений, при 640 — **0, 2 и 0**. Не все неразмеченные фрагменты представлены в искусственном пуле; качество реальной детекции в эти цифры не входит.

**Важное ограничение:** это не обученная Graph-LIRA в полном понимании и НЕ оригинальный AZConv. Здесь использована логистическая классификация по геометрическим и вручную созданным анизотропным признакам (честно названная `axial_geometry_proxy`). Разные 3 seed — три разделения **одной плёнки**, а не независимые камеры или заливки. Нельзя утверждать «85% распознавания без людей на новых BMP».

## Реализованный исследовательский код

- `bubble_chamber/s14_small_supervision.py`: детерминированный эксперимент с расходом экспертных решений, сравнение случайного/неуверенного/сбалансированного активного отбора, пороги только на validation и запрет использовать неизвестное как отрицательное.
- `bubble_chamber/s14_fewshot_graph.py`: обучение небольшого классификатора связывания по честным экспертным парам из P0, проверка происхождения фотографии и review JSON, автономное вычисление вероятностей для следующего кадра, графовые ограничения. Без независимой калибровки соединения только предварительные.
- `bubble_chamber/s14_sparse_teacher.py`: частичная human-BCE + контролируемое псевдообучение на ещё не размеченных пикселях; оригинальные AZConv/UNet не изменены.
- `scripts/research/bubble_chamber/s14_train_sparse_anza.py`: обучение оригинальной AZUNet по пользовательским PNG/BMP и частичным маскам 0/1/255, EMA teacher, проверка SHA и разделения кадров, сохранение `best.pt` / `last.pt`. Метрика на валидации — **ошибка по известным пикселям**, не полный Dice реальных изображений.
- `scripts/research/bubble_chamber/s14_graph_from_reviews.py`: потребление оригинальных результатов P0 и подписанных решений эксперта, получение portable JSON-предиктора и осторожного вывода связей на новых кадрах без разметки. **Калибровка на отдельном запуске сама по себе не разрешает физическое автоматическое объединение**: нужен дополнительно независимый тест по реальным проверенным маскам и версиям стерео-/магнитной калибровки.
- `bubble_chamber/s14_anza_frontend.py` и `scripts/research/bubble_chamber/s14_predict_new_photo.py`: загрузка оригинальной AZUNet из проверенного `best.pt`, получение сегментов и координат на новом изображении, затем оценка гипотез Graph-LIRA. Без научно завершённой валидации результат помечен `PROVISIONAL` и физические соединения не подтверждаются.

**Технический smoke с настоящими исходниками AZUnet (на созданных программой, не экспертных, изображениях):** 6 обучающих фрагментов с 1/0/255-метками, 3 валидационных и 6 без меток, 25 эпох. Ошибка BCE только по известным точкам на валидации снизилась у исходной AZUNet с 0.687 до 0.126; у U-Net на том же smoke с 0.729 до 0.523 (минимум 0.443). **Это не Dice и не реальное качество — простейшие искусственные картинки**. При высоких порогах доверия учитель не добавил ни одного псевдопикселя: код правильно отказался от неуверенных меток. После этого pipeline на одном новом искусственном изображении выдал 7 сегментов и 4 предварительные гипотезы соединения, ни одну не объявляя физически подтверждённой. Это подтверждает работоспособность цепочки кода, но также демонстрирует необходимость Graph-LIRA после ANZA.

Локальные автоматические тесты включают реальный forward/backward оригинальной `AZUNet` по скудной 0/1/255-разметке и тест полного прохода обучения на синтетических scribbles. Пользовательские оригинальные снимки, raw измерения и физические истины в Git не включаются.

## Критерий приемки будущей системы

- На новых, не участвовавших в обучении плёнках/запусках: отдельная оценка контуров треков, completeness, *ложных объединений* на кадр и 2D аппроксимаций.
- На пропане и водороде — **раздельные показатели и доменная калибровка**, без обещаний, что один обученный вес переносится автоматически.
- Эксперт вначале размечает ограниченный набор; после завершения проверки повседневный вывод работает без обязательной разметки каждого кадра. На необычных/неуверенных эпизодах алгоритм имеет право отказаться от физической интерпретации; это не означает, что физик должен обводить все снимки снова.
- Сначала необходимо получить фотографии и экспертные траектории, которые реально соответствуют **одним и тем же кадрам/проекциям**. В доступном `1mH2Data` есть координаты плёнки 070, но нет соответствующих BMP; H50Z — другой источник. Автоматически приравнивать их нельзя.

## Как выглядит минимальный файл с экспертной разметкой

`reviewed_manifest.json` привязывает исходный BMP/PNG и `mask.png` к `film_id`, `run_id`, `frame_id`, `split` и SHA256 обоих файлов. Метки PNG имеют значения **1 = подтверждённый трек**, **0 = подтверждённый артефакт**, **255 = никто не знает**. Нельзя маркировать всё остальное нулём. Неразмеченные кадры допускаются с `split=unlabeled` и вообще без поля `mask`. Папки исходных фильмов остаются локальными.

Отдельно нужна разметка связей `same_track / different_track / uncertain`, привязанная к оригинальному `P0 result.json` и эксперту. Имеющийся интерфейс `make_track_review.py` и `review.py` позволяет такую разметку создавать без повторного рисования всей фотографии.

## Воспроизведение

```bash
python scripts/research/bubble_chamber/s14_small_label_graph_study.py \
  --measurements /private/1mH2Data/S1 --out-dir results/bubble_chamber/s14

# Если имеются подтверждённые экспертом sparse-маски (1/0/255):
python scripts/research/bubble_chamber/s14_train_sparse_anza.py \
  --manifest /private/sparse_tile_manifest.json \
  --out-dir results/bubble_chamber/s14_anza --model azunet

# Реальные P0 review-пары и новые неразмеченные P0-предложения:
python scripts/research/bubble_chamber/s14_graph_from_reviews.py \
  --review-manifest /private/p0_review_index.json \
  --train-run-id hydrogen_run_id \
  --out-dir results/bubble_chamber/s14_graph

# Обработка НОВОГО кадра без экспертной разметки этого кадра:
python scripts/research/bubble_chamber/s14_predict_new_photo.py \
  --image /private/new_image_crop.bmp \
  --model-json results/bubble_chamber/s14_graph/relation_model.json \
  --az-checkpoint results/bubble_chamber/s14_anza/best.pt \
  --film-id filmNew --run-id runNew --frame-id frameNew \
  --out-dir results/bubble_chamber/new_inference
```

**Следующая научная проверка:** получение небольшого парного датасета `оригинальное изображение + подтверждённые линии + подтверждённые артефакты + same/different связи`, затем несколько запусков teacher-student Graph-LIRA vs ordinary U-Net/ConvGraph при одинаковом бюджете человеческой разметки, с независимым тестом на другой заливке/съёмочной серии.
