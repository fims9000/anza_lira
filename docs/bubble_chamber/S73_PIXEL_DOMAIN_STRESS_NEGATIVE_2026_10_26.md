# S73 — поведение фиксированной S72-схемы при моделируемых искажениях изображения

**26.10.2026 · ANZA-LIRA-BC-S73-20261026 · machine-only, synthetic-only.** Исследовательская ветка: `research/bubble-chamber-graph-lira`.

## Проверенный научный вопрос

S72 обнаружил условную пользу от выбора метода по направлению переноса: 005→006 — S68 «разделение ветвей + уточнение концов», 006→005 — исходный S39. S73 проверяет, не пропадает ли эта польза при стандартных искажениях пикселей. **Схема S72, геометрический скорер, все пороги и S69 исправленный оценщик заморожены**. Подбор модели или метода по результатам S73 отсутствует.

**Данные:** 96 новых искусственных сцен (семена 20267303/04/13/14) с двумя искусственными трёхчастными траекториями и обманным штрихом в каждой. Итого 384 условно правильных соединения. Геометрия визуализирована на двух настоящих H50Z фотофонах одного запуска, которые **не размечены физиками**. Исходные геометрии из visualMetro 070, отдельной плёнки; split 79/30/36 по кадрам, как в S72. Для каждой из 96 сцен проверены её исходное изображение и четыре изменения пикселей: контраст 0.72, Gaussian blur σ=1.1 px, гауссов шум σ=9 цифровых уровней и 2 искусственных 1-пиксельных прямых штриха. Это **480 наблюдений тех же 96 сцен**, а не 480 независимых физических случаев.

## Обобщённые результаты (S39 → зафиксированный по S72 выбор)

| Условия | Правильные искусственные стыки | Остальные предложения | Полные 3-фрагментные искусственные цепочки | Сцены с некорректным предложением |
|---|---:|---:|---:|---:|
| Исходное изображение | **51 → 50** | 41 → **35** | **16 → 14** | 30 → 26 |
| Понижение контраста | 50 → 50 | 45 → **38** | **14 → 13** | 33 → 29 |
| Gaussian blur σ=1.1 | 11 → **13** | 32 → **20** | 2 → 2 | 27 → 20 |
| Цифровой шум σ=9 | 37 → **43** | 51 → **36** | 6 → **7** | 34 → 28 |
| Две искусственные царапины | 34 → **35** | 57 → **45** | 5 → 5 | 46 → 36 |

**Результат: отрицательный по заранее замороженному критерию.** Схема S72 заметно сокращает число синтетически некорректных предложений во всех стрессорах, особенно под шумом/размытием. Но она теряет 1 правильный стык и 2 полные цепочки даже **без** искажений на новых сценах и теряет одну полную цепочку при пониженном контрасте; безусловная полнота не гарантирована. Замороженный S72 выбор не прошёл 8 контрольных ячеек «направление × стрессор» по всем ограничениям. **Ни один алгоритм автоматически не внедрён на реальные данные.**

## Сильнейший наблюдаемый отказ — размытие

Сравним **одни и те же 96 искусственных сцен** без обработки и после σ=1.1 px Gaussian blur:

- S39: правильные соединения **51 → 11**, полностью собранные искусственные цепочки **16 → 2**.
- Зафиксированная S72-схема: правильные соединения **50 → 13**, полные цепочки **14 → 2**.

Никакой новый порог не подбирался, модель не переобучалась. Дефекты и артефакты смоделированы программно; модель настоящей пузырьковой камеры по этим данным не идентифицируется. Улучшение изолированной графовой оптимизации не компенсирует исчезновение/слияние линий при размывании.

## Методика, реплей, цифровая сохранность

- Протокол заранее зафиксирован в `S73_FROZEN_PIXEL_DOMAIN_STRESS_TEST_2026_10_26.md`. Новые TEST seeds 20267303/04/13/14, 24 сцены на seed; все стрессоры применяются **к тем же самым** сценам.
- Реальный пиксельный ввод — `uint8` 192×192. `perturb` принимает только пиксели, вид и seed; GT нигде не участвует в преобразованиях. Все четыре оригинальных детектора предсказывают до того, как S69 оценщик получает координаты искусственного источника.
- Точная S72 CAL SHA-256 `1ed7e58667aaab1a7d5ba91252db64b38bf8d3da517396b9e18e9e6bb484a952`; S72 метод 005→006 = S68 refine, 006→005 = S39.
- В JSON `S73_PUBLIC_FRESH_DOMAIN_STRESS_2026_10_26.json` сохранены суммы и парные 95% bootstrap CI с пересчётом **полных синтетических сцен**, раздельно по семенам/направлениям/стрессорам. Корректность на независимых реальных физ. запусках **не измерена**.
- В репозиторий входят только исходный код, тесты, публичные агрегаты, хеши протоколов и ID эксперимента. Приватные H50Z PNG/BMP, 7z, измеренные координаты, individual hypotheses и веса моделей не публикуются.

**Следующий научный приоритет:** надёжность image-derived instance extraction при реальном размывании, восстановление отдельных ветвей и проверка метрик по новому физическому запуску/источнику фонов без подстройки S73 TEST.
