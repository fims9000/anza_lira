## 2. Что действительно осталось

**A. Подключить закрытые данные, которые ранее предоставлялись для исследований.**

- 21 оригинальный 512×512 H50Z-фрагмент фото `005` и 18 фото `006` — **39 фрагментов, но только один физический запуск**; они не являются 39 независимыми событиями.
- Каталог measured visualMetro `1mH2Data/S1` с аудированными кадрами плёнки **070**, дающий прежнее разбиение 79 TRAIN / 30 CAL / 36 TEST.
- Данные должны храниться вне публичного GitHub, например в закрытой рабочей директории. Нельзя дописывать под них значения, подменять фото генератором или переносить измерения между различными физическими событиями.

**B. Получить S85 численно, без подглядывания в TEST.**

1. `preflight`: проверить наличие/формат, 21+18 изображений, исходный split, SHA-256 предыдущих методов.
2. `TRAIN`: на **64 новых синтетических сценах для каждого направления** и трёх состояниях пикселей оценить количество однозначных дополнительных искусственных кандидатов. Если недостаточно — **ABSTAIN**, а не фиктивное обучение.
3. `CAL`: на **24 иных сценах для каждого направления** проверить исходный S72 против обученного p85/p95. Зафиксировать выбранный метод и SHA модели **до TEST**.
4. `TEST`: на **96 новых искусственных сценах на состояние** (2 направления ×2 seed ×24 сцены) измерить число полностью восстановленных 3-фрагментных цепочек, верные/неподтверждённые стыки, shape/endpoints, включая clean/blur σ1.1/σ1.6/scratch+grain. TEST не меняет порогов.
5. Повторить TEST с неизменными входами; проверить совпадение байтов; затем сделать только безэталонный машинный аудит 39 настоящих H50Z-фрагментов и приватную офлайн-галерею.
6. Записать агрегированные цифры, bootstrap по сценам, заключение **negative / inconclusive / synthetic improvement**. Никогда не называть этот этап физической валидацией H50Z.

**C. Только после этого — независимая физическая проверка.**

Нужны новые физические запуски, отличные от нынешних `005`/`006`, а также независимо подтверждённые специалистами траектории/стыки. Желательно согласовать протокол оценки: единица независимости — физический запуск/кадр, связь правильна только при доказанной идентичности трека; покрытие редких событий и ложных соединений считается отдельно. Пользователю не нужно самостоятельно размечать тысячи снимков: модель генерирует кандидатов; физики могут выбрать небольшой верификационный набор и подтверждать/опровергать **уже предложенные** связи. До такого контроля нельзя оценить точность восстановления физических частиц.

## 3. Содержание выходного пакета для физиков

- **Что обнаружено автоматически**: исходные 2D-линии S72, дополнительные гипотезы S85, предложенные глобальным графом соединения (все `UNKNOWN`).
- **Что измерено**: синтетические верные/неверифицируемые соединения на искусственно добавленных линиях поверх H50Z-фонов, условия теста и интервал неопределённости.
- **Чего нет**: доказанной идентичности физической частицы, 3D-реконструкции, импульса/массы и оценки клинического/физического результата. Измеренные координаты film070 — не H50Z GT.
- **Отдельное предупреждение для ML**: отрицательная метка «далеко от искусственных вставок» означает «не является одной из **вставленных** искусственных линий». Такая линия может быть настоящим H50Z-событием и **не должна** называться ложной физической частицей. Обученный на этом proxy классификатор непригоден для безусловного отбрасывания реальных H50Z-линий.

## 4. Команды для закрытого вычислительного окружения

В корне **полного** репозитория, не только архива с новыми S85-модулями:

```bash
python scripts/research/bubble_chamber/s85_release_manager.py preflight \
  --visualmetro /PRIVATE/1mH2Data/S1 --photo-tiles /PRIVATE/tiles \
  --out /PRIVATE/S85_PREFLIGHT.json --strict

python scripts/research/bubble_chamber/s85_release_manager.py run-all \
  --visualmetro /PRIVATE/1mH2Data/S1 --photo-tiles /PRIVATE/tiles \
  --private-out-dir /PRIVATE/S85_RESULTS

python scripts/research/bubble_chamber/s85_private_review_gallery.py \
  --visualmetro /PRIVATE/1mH2Data/S1 --photo-tiles /PRIVATE/tiles \
  --train-models /PRIVATE/S85_RESULTS/S85_TRAIN_MODELS_PRIVATE.json \
  --calibration /PRIVATE/S85_RESULTS/S85_FROZEN_CAL_PRIVATE.json \
  --private-out-dir /PRIVATE/S85_REVIEW_PRIVATE
```

Если запуск прерван после сохранения части артефактов: добавить `--resume` только к `run-all`; старые файлы не будут перезаписаны. Неподходящий SHA, загрязнение публичной директории приватными моделями, неоднозначная фаза или несовпавший повтор TEST завершаются отказом.

Исследовательские тесты кода: `python -m pytest -q tests/test_s[0-9]*.py`. Тесты готовности/оркестрации: `python -m pytest -q tests/test_s85_*.py`. Для полного репозитория нужно восстанавливать исходные модули других областей, а не ослаблять существующие тесты.

## 5. Решение о завершённости

- **Инженерный прототип:** может считаться готовым к закрытому исследовательскому запуску после успешной CI и проверки manifest/дополнительных тестов.
- **Исследование искусственных вставок на H50Z-фонах:** НЕ завершено, пока нет замороженного TRAIN/CAL/TEST и истинных агрегатов S85.
- **Физическое распознавание треков H50Z:** НЕ доказано без независимых запусков и экспертной валидации.
- **Внедрение**: **NO GO** для автоматического физического соединения; текущий основной метод S72 как исследовательский baseline.

**После восстановления приватных входов требуется не новый порог S86, а именно полный запуск S85 и очная проверка готовых машинных гипотез физиками.**
