# S38. Независимая проверка ANZA–Graph-LIRA на реальных фотографиях H50Z

**Дата:** 25.10.2026. **Ветка:** `research/bubble-chamber-graph-lira`. **Статус:** инструменты независимой ручной проверки готовы; настоящих экспертно заверенных треков/связей пока нет. Это **не новая проверка точности распознавания физических треков**.

## 1. Установленный источниковый факт

Приватный S35 содержит **две** исходные фотографии H50Z одного физического запуска, из которых получены **39** контролируемых по SHA-256 изображений 512×512: 21 из 005 и 18 из 006. Существуют **133 машинные гипотезы контуров** (61 LSD, 36 классическая геометрия, 36 исходная AZUNet) и **28 гипотез соединения** (11 на 005, 17 на 006). Физический источник для 28 пар тот же, что для 133 фрагментов, поэтому их нельзя использовать как независимую тестовую выборку.

**Ключевая новая диагностика:** **17 из 39 участков вообще не содержат машинных гипотез линий** (43,6%). Эти участки не являются проверенным отрицательным классом. Прежний обзор только машинных предложений создавал *verification bias*: при проверке исключительно предложенных линий невозможно обнаружить пропущенные моделью физические треки и оценить нативную полноту. Не следует трактовать отсутствие машинной линии как отсутствие частицы.

## 2. Исправленная процедура S38

1. Два проверяющих **независимо** обрабатывают один и тот же набор в раундах A и B. Очереди охватывают **все 39 участков**, **все 133 машинные линии** и **все 28 пар**, но порядок различается. Это уменьшает влияние порядка, не гарантируя статистическую независимость решений. Код проверяющего — псевдоним, не доказательство квалификации или личности.
2. Перед разметкой **скрыты и модельные оценки, и название алгоритма**. Снятие слепого режима запоминается при экспорте, чтобы такие оценки нельзя было молча включить в blinded-анализ.
3. В режиме **«Все участки»** нужно осмотреть каждый исходный участок; отдельная вкладка **«Без кандидатов (17)»** позволяет сначала проверить 17 участков без машинных предложений. Любой явно увиденный пропущенный след добавляется **вручную** отдельной кривой. Запись `NO_ADDITIONAL_LOCAL` не считается отрицательной пиксельной маской или доказательством отсутствия других треков.
4. В режиме **«Линии»** оцениваются 133 гипотезы: принять, отклонить, не уверен. Разрешено редактировать центральную кривую с 2–128 конечными координатами внутри 512×512; принятие и ручная коррекция остаются предварительными.
5. В режиме **«Связи»** решение same/different разрешено только после предварительного принятия **обеих** составляющих линий; иначе связь остаётся `UNKNOWN`. Отказ `UNSURE` сохраняется как неизвестность, не как отрицательный класс.
6. Каждый проверяющий экспортирует **отдельный приватный S31-совместимый JSON** с метаданными `s38_review_session`, картой осмотра всех участков и новыми ручными линиями. Никакого серверного сохранения нет, поэтому перед закрытием необходимо экспортировать файл.
7. Сравнение A/B выполняется **вне браузера**, выводит приватный список разногласий и публично допустимые **только агрегированные счётчики**. Даже согласие двух проверяющих не становится физической истиной автоматически. Новые вручную нарисованные линии из двух раундов не сопоставляются автоматически: они требуют независимого разбора.

## 3. Воспроизводимые артефакты

В публичный GitHub допустимы **только** код и агрегированные факты:

- `bubble_chamber/s38_review_protocol.py` — охват 39/133/28, независимые очереди, контроль структуры и безопасное двойное сравнение;
- `scripts/research/bubble_chamber/s38_review_workbench.html` — статический HTML без частных пикселей и координат;
- `scripts/research/bubble_chamber/s38_build_private_workbench.py` — генерация **приватного** ZIP, проверка декодированных пикселей, source SHA и source template;
- `scripts/research/bubble_chamber/s38_adjudicate_reviews.py` — раздельные приватный worklist и агрегированный отчёт;
- `docs/bubble_chamber/S38_SOURCE_INVENTORY_PUBLIC.json` — агрегированный протокол инвентаризации;
- `tests/test_s38_blinded_double_review.py` — отрицательные тесты против подмены источника, домыслов связи и неверных координат.

**Запуск разметчика** (только локально, оригинальные фотографии и исходный ZIP не коммитить):

```bash
python scripts/research/bubble_chamber/s38_build_private_workbench.py \
  --private-source-zip /private/S35_ANZA_FRAGMENT_LINK_RESEARCH_PRIVATE.zip \
  --expected-source-sha256 903cfae7e8742bab203ee12aecfa454b75a71454dbabaee630982557a84b13d7 \
  --out /private/S38_PRIVATE_H50Z_DOUBLE_REVIEW.zip \
  --public-inventory /private/S38_source_inventory.json
```

Распаковать `S38_PRIVATE_H50Z_DOUBLE_REVIEW.zip` **целиком** и открыть `S38_REVIEWER/index.html`; оригинальные PNG находятся в соседнем каталоге `crops/`. Два независимых экспорта A и B:

```bash
python scripts/research/bubble_chamber/s38_adjudicate_reviews.py \
  --private-source-zip /private/S35_ANZA_FRAGMENT_LINK_RESEARCH_PRIVATE.zip \
  --review-a /private/S38_private_review_round_A.json \
  --review-b /private/S38_private_review_round_B.json \
  --private-adjudication-json /private/S38_ADJUDICATION_WORKLIST.json \
  --public-aggregate-json /private/S38_AB_AGREEMENT_AGGREGATE.json
```

**Экспортированный JSON содержит частные идентификаторы, кривые и ответы; он никогда не публикуется.** Публичный файл `S38_AB_AGREEMENT_AGGREGATE.json` можно публиковать только после проведения реальных проверок, а не на вымышленных ответах для тестирования интерфейса.

## 4. Научная интерпретация и границы

- **Реальная точность сегментации, track recall, 3D-связность, физический momentum/PID:** не измерялись. В данных отсутствуют физически сертифицированные маски, сопоставленные 3-view кадры и независимые runs.
- Ручное подтверждение **только машинных предложений** способно оценивать качество найденных кандидатов, но не чувствительность к пропущенным трекам; именно поэтому теперь добавлен *полный обзор всех кропов*.
- Согласованные локальные решения A/B могут стать материалом для **дополнительной независимой экспертной адъюдикации**, а не готовой физической GT. Неопределённые и конфликтные примеры исключаются из числителя и знаменателя локального обучающего набора и **не превращаются в нули**.
- Если цель — риск хотя бы одного ложного физического соединения на событие <2%, то даже для **одного фиксированного метода**, при **нуле ошибок** и **149 независимых одинаково распределённых событиях**, односторонняя непоправленная 95%-я граница лишь опустится ниже 2%. Нынешние 39 кропов из **одного запуска** этому условию не соответствуют; множественный выбор методов и сдвиг домена требуют ещё более строгой проверки.
- Настоящий положительный исследовательский этап после разметки: раздельные запуски/плёнки на train/cal/test; реальные pixel-centerline GT и физические негативные пары; сильные Frangi/Steger/U-Net/ANZA baseline на одинаковых splits; событие-уровневая оценка ложных joins и abstain; bootstrap по независимым источникам, а не по окнам.

**Локальная проверка:** 31 source-only автоматический тест S35–S38 прошёл, а офлайн-HTML протестирован в Chromium на настоящих 39 PNG через изолированную подачу изображений (отрисовка, слепой режим, ручная поправка/новый трек, требование двух принятых линий для пары, JSON экспорт/импорт). Синтетические тестовые ответы были удалены и не являются разметкой физика. Удалённые GitHub Actions для S38 этим запуском ещё не подтверждены.

**Критерий остановки:** пока не предоставлена проверенная физиками разметка и независимые съёмки, **не обучать физический production relation head**, не включать автосоединение и не заявлять клиническую/физическую применимость. Допустимо только неавтоматическое ранжирование гипотез и подготовка исходных данных к разметке.

После двух реальных независимых экспортов агрегатор также вычисляет долю наблюдаемого согласия и κ Коэна **только на парах ответов с двумя явными решениями**, отдельно для линий и связей. Если данных или вариативности классов недостаточно, κ остаётся `null`. Эти значения характеризуют условную воспроизводимость **предварительных решений проверяющих**, а не точность распознавания частиц; при двух фотографиях из одного физического запуска доверительные интервалы до независимого источника не интерпретируются.
