# ANZA–LIRA S56–S57: сборка целых 2D-траекторий из машинных фрагментов

**Дата:** 26.10.2026. **Ветка:** `research/bubble-chamber-graph-lira`. **Состояние:** эксперимент воспроизведён на искусственных разрывах; офлайн-демонстратор реальных фотографий создан. **Физически подтверждённых соединений: 0.**

## Научный вопрос

Может ли глобальная оптимизация по **двум концам каждого фрагмента**, с запретом неоднозначных соединений, лучше восстановить искусственные цепочки из трёх отрезков, чем прежний локальный выбор единственного соседа (S39), при приемлемом числе ложных стыков? В качестве сильного практического контроля используется жадная сборка по концам, допускающая две связи для внутреннего фрагмента.

Это проверка **алгоритма построения графа на 2D-проекциях**, а не полной физической реконструкции. В S56 передаются геометрические положения фрагментов с искусственно внесённой ошибкой извлечения; они получены из симулятора, а не от реального сегментатора H50Z. Следовательно, приведённые значения НЕ являются end-to-end точностью обработки фотографии.

## Данные и ограничения

- Геометрия кривых: 145 полных кадров исходных **операторских измерений** visualMetro фильма 070; прежнее фиксированное разделение S37 — **79/30/36 кадра** для обучения/калибровки/теста. Пересечений кадров между группами нет. Измерения относятся к другой плёнке и **не являются истинной пиксельной разметкой H50Z**.
- Фоны: 39 настоящих участков из двух фотографий H50Z (`005`, `006`), принадлежащих **одному физическому запуску**. Обучение/калибровка на одном фото, тест на другом и наоборот.
- В каждой *искусственной сцене* присутствуют две исходные кривые, разрезанные на **три фрагмента по 31 точке**, и один дополнительный неправильно сопоставляемый фрагмент. Сценарии: `parallel`, `near_parallel`, `crossing`, `scratched`, `empty_gap`. Из 21 парной гипотезы четырём присвоена метка «связь» **только по исходному генератору**.
- Зафиксированы до проверки: на направление 64 сцены train, 64 calibration и **2 × 64 test**. Суммарный тест — **256 искусственных сцен, 1024 потенциально правильных стыка и 512 возможных полных трёхчастных цепочек**.
- Единая оценочная модель для всех вариантов: шесть классических геометрических признаков S35 + StandardScaler + LogisticRegression (`C=0.3`, class-weight balanced). Калибровочный порог — только по отрицательным парам CAL (эмпирический максимум 5% FPR). Жёсткая устойчивость выбора — разница полезности не меньше `0.04`. Ни тестовая метка, ни метка физического трека при выборе параметров не использовались.

Замороженный до теста протокол: `S56_FROZEN_GLOBAL_PATH_ASSEMBLY_PROTOCOL_2026_10_26.md`. Агрегированные числовые результаты: `S56_PUBLIC_GLOBAL_PATH_RESULTS.json`.

## Основной результат на 256 искусственных сценах

| Алгоритм | Правильные стыки | Ложные стыки | Сцен с хотя бы одним ложным стыком | Полностью собранных искусственных цепочек | Сцен с полностью правильной сборкой обеих цепочек |
|---|---:|---:|---:|---:|---:|
| Прежний взаимно-лучший выбор по узлу S39 | 88 | 15 | 15 | 0 | 0 |
| Жадный выбор по каждому концу фрагмента | **441** | 36 | 35 | **129** | **34** |
| Глобальная оптимизация целого графа + отказ | 246 | **13** | **12** | 66 | 16 |

**Компромисс:** глобальная сборка восстановила **246/1024 = 24,0%** допустимых искусственных стыков, тогда как жадная — **441/1024 = 43,1%**. При этом ложных стыков получилось **13 против 36**. Среди предложенных соединений доля правильных на этой симуляции — приблизительно **95,0% глобально** и **92,5% жадно**; это **не** физическая precision на настоящих частицах. Старый S39 выбирает только одну связь для целого узла, поэтому он **по определению не умеет** собирать тройные цепочки; отсутствие полных цепочек в таком сравнении не является эмпирической победой новой модели.

## Повторяемость между направлениями и неопределённость

| Направление / тестовый seed | AUROC общих парных признаков | Глобальные: правильные / ложные | Жадные: правильные / ложные | Полных цепочек, глобально / жадно |
|---|---:|---:|---:|---:|
| 005→006 / 20265603 | 0,950 | 88 / 6 | 128 / 11 | 24 / 42 |
| 005→006 / 20265604 | 0,945 | 61 / 1 | 105 / 11 | 16 / 27 |
| 006→005 / 20265613 | 0,944 | 47 / 4 | 101 / 9 | 12 / 30 |
| 006→005 / 20265614 | 0,946 | 50 / 2 | 107 / 5 | 14 / 30 |

Дополнительно рассчитаны **парные 95% bootstrap-интервалы по целым синтетическим сценам** для разности числа правильных и ложных стыков; они сохранены отдельно для всех четырёх тестов в JSON. На последнем тесте интервал разности ложных соединений глобального и жадного методов включает ноль: универсальная гарантия снижения ошибки **не доказана**. Ни один из этих интервалов не относится к независимым физическим запускам.

Глобальный вариант использует целочисленную задачу максимальной суммарной полезности при ограничении одного соединения на каждый конец линии, без замкнутых циклов (для данного узкого класса **открытых** искусственных траекторий), а затем отклоняет стыки, чьё исключение не меняет глобальный оптимум достаточно сильно. При отказе решателя модель возвращает пустой список предложений. **Физические замкнутые треки и вершины взаимодействий возможны**; такой приор нельзя без проверки переносить на них.

## Применение к существующей машинной разметке H50Z

**Без ручного вмешательства** повторно обработаны все исходные S39 графы. Сохранены исходные 39 фрагментов изображений, 567 машинных линий и 182 кандидатных стыка после NMS (511 графовых узлов). Использована модель, обученная на искусственных сценах на *другой* фотографии H50Z, а порог был выбран только по её синтетической калибровке.

- Глобальный граф предложил **37 из 182 стыков**; это машинные гипотезы, не настоящая физическая GT.
- **6 из 37** совпали с ранее сформированными предупреждениями S40–S52 (реперы, повторяемость, пересечения). Предупреждения не удалены и видны в просмотрщике.
- Все остальные связи, даже без известных предупреждений, имеют статус **`UNKNOWN`**. Не создано ни одной физически подтверждённой связи, восстановленной 3D-траектории или метки массы/заряда частицы.
- Числа S56 нельзя использовать как доказательство качества AZUNet, поскольку S56 оценивает геометрию искусственных фрагментов, а не обучает и не оценивает сегментационную нейросеть на новой экспертной разметке.

## Дальнейший научный шаг

На следующем этапе проверить **смешанный граф**, в котором линии извлечены уже непосредственно с фотографий, без предоставления точных машинных/синтетических координат; сравнить этот end-to-end конвейер с текущим oracle-geometry диагностическим тестом. Отдельно исследовать безопасное обнаружение вершин и допустимых циклов без использования ложных физически утверждённых связей. Окончательное доказательство реальной точности и переносимости потребует независимых снимков/физической истины, но текущая работа и демонстрация не требуют пользовательской ручной разметки.
