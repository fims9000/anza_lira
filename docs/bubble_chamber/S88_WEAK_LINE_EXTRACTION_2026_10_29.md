# S88: поиск слабых криволинейных кандидатов на фотографиях пузырьковых камер

**Статус на 29 октября 2026 г.:** инженерный прототип исследовательского детектора; **нельзя** использовать для автоматического объявления физических траекторий, идентификации частиц или подтверждённой 3D-реконструкции. Код и все открытые тесты содержат **только синтетические изображения**. Реальные H50Z, приватные измеренные координаты и веса модели не публиковались.

## Что добавлено

1. `bubble_chamber/s88_weak_ridges.py` — классический, **необучаемый** детектор тёмных криволинейных структур, вдохновлённый методом Steger. Для масштабов σ=1,0/1,6/2,4 вычисляет собственные значения матрицы Гессе, локальное направление линии и смещение её центра вдоль нормали `t = - (∇I · n) / (nᵀHn)`. Фильтрует низкую анизотропию, несогласованные нормальные максимумы и светлые структуры, затем выполняет гистерезис по условной *signal-to-noise proxy* и подавляет крошечные компоненты. Вспомогательные карты: масштаб, локальная касательная, субпиксельная оценка, интенсивность отклика. **Эта интенсивность не является вероятностью правильной физической траектории.**
2. `bubble_chamber/full_bmp_segmentation.py` и CLI — дополнительный `--method s88-steerable`, без изменения старых значений по умолчанию для contrast/Frangi/AZUNet и без подключения графового автоматического слияния. Применим к полному BMP по ограниченным по памяти тайлам, сохраняет координаты исходного кадра, маски и манифест с SHA-256. Для обнаруженных фрагментов дополнительно экспортирует `subpixel_centerline_xy_source_px` (локальная оценка центра в исходных пикселях), медиану отклика и характерный масштаб. Эти значения не являются физической пространственной калибровкой. `0` в маске — **нет кандидата**, а не экспертно размеченный фон; `255` — **кандидат UNKNOWN**, не доказанный трек.
3. `bubble_chamber/s88_generated_benchmark.py` — воспроизводимый полностью **сгенерированный** CAL/TEST, в котором известны только искусственно нарисованные центральные линии. Два искусственных режима: `faint_grain` и `blurred_scratches` (градиенты засветки, зерно/точки, кривизна, размытие, посторонние царапины). 16 CAL-сцен = 8 seed × 2 режима; 24 TEST-сцены = 12 seed × 2 режима. Seed CAL = 1000…1007; seed TEST = 5000…5011, пересечения нет. Каждый seed создаёт искусственную сцену, а **не** независимую физическую экспозицию.
4. Сравнение **трёх** методов на одинаковых сценах, при общем CAL-ограничении средней площади кандидатных пикселей ≤ 1,5% и выборе порога **только по CAL**. Для каждой сцены: доля искусственной центральной линии, найденной на расстоянии до 2 пикселей; доля предсказанных пикселей дальше 3 пикселей от введённой линии (ложные кандидаты *относительно искусственной инъекции*), площадь выделения. Парный бутстрэп — по **сгенерированным сценам**, не по пикселям. Протокол не является реальной оценкой качества на H50Z.

## Проверенные результаты на искусственном TEST

Источник — [S88_GENERATED_ONLY_CAL_TEST_METRICS_2026_10_29.json](S88_GENERATED_ONLY_CAL_TEST_METRICS_2026_10_29.json), который включает полный список CAL-порогов, выбранный CAL-порог, TEST-метрики по двум режимам, 24 отдельных искусственных сцены для каждого метода, парные интервалы и хеши исходников.

| Метод | CAL-порог | TEST покрытие введённой осевой линии (≤ 2 px) | Площадь кандидатов | OFF-line пиксели (> 3 px) |
|---|---:|---:|---:|---:|
| Contrast | 7.0 | 62.61% | 0.897% | 0.0445% |
| Frangi | 0.125 | 80.67% | 1.478% | 0.3557% |
| **S88** | **high 1.7 / low 0.816** | **99.91%** | **1.265%** | **0.2531%** |

Парный TEST-эффект S88 на искусственной осевой линии: против Contrast **+37,30 процентного пункта**, 95%-й интервал по сценам **+31,32…+43,02 п.п.**; против Frangi **+19,24 п.п.**, интервал **+9,91…+30,24 п.п.** У S88 **выше доля посторонних кандидатов, чем у Contrast**: +0,2086 процентного пункта относительно пикселей всего изображения; против Frangi — на 0,1026 процентного пункта меньше. **Не следует называть этот тест оценкой recall, precision или ложных соединений физических частиц.** Не проверялись независимые фото реальных физических запусков или идентичность частиц.

**Ограничения:** высокая доля покрытия искусственной осевой линии при допуске 2 px не гарантирует топологически цельную маску, правильные экземпляры, точные концевые точки или связность через настоящие пропуски. Пример с реальной царапиной может быть неотличим от слабой линии исключительно по интенсивности. Дополнительный порог и уровень шума зависят от снимка. Фиксированные значения выше нельзя считать калиброванными для H50Z. S72/S85 не переоценивались и не изменялись.

## Запуск на закрытом BMP

Только в приватном каталоге **вне git** и только после проверки прав доступа:

```bash
python scripts/research/bubble_chamber/physicists_full_bmp_segmentation.py \
  --bmp /PRIVATE/H50Z/H50Z_030_01_005.bmp \
  --private-out-dir /PRIVATE/results/H50Z_S88_RESEARCH_ONLY \
  --method s88-steerable --core 384 --halo 48 \
  --s88-high-snr 1.7 --s88-low-snr 0.816 --full-mask-npy
```

Параметры 1.7 / 0.816 — **искусственно откалиброванный режим повышенной чувствительности**, а не физическая калибровка. Более консервативные значения по умолчанию CLI: high 3.4 / low 1.7. При реальных данных оценивать **оба**, не называть любой из них наилучшим до проверки физиками. При прерывании использовать `--resume` **с теми же параметрами и тем же исходным BMP**. Результаты хранятся приватно: `manifest.json`, `masks/*.png`, `fragments.ndjson`, `tiles.ndjson`, `index.html`, `full_candidate_mask.npy` (по флагу). На первичной стадии Graph-LIRA только в режиме гипотез, без физического автослияния.

Дополнительная сборка только наблюдаемой 8-связности через соседние тайлы:

```bash
python scripts/research/bubble_chamber/physicists_s87_seam_continuity.py \
  --s86-dir /PRIVATE/results/H50Z_S88_RESEARCH_ONLY \
  --private-out-dir /PRIVATE/results/H50Z_S88_SEAM_REVIEW \
  --bmp /PRIVATE/H50Z/H50Z_030_01_005.bmp
```

S87 не достраивает невидимые отрезки. Не подменяйте физическое подтверждение программной непрерывностью. Извлечение из H50Z с настоящими экспертными масками **не проверено**; статистики по реальной точности пока нет.

## Воспроизведение открытых результатов

```bash
python -m pytest -q tests/test_full_bmp_segmentation.py tests/test_s87_seam_continuity.py tests/test_s88_weak_ridges.py
python scripts/research/bubble_chamber/s88_benchmark_weak_lines.py \
  --output /tmp/S88_GENERATED_ONLY.json --cal-count 8 --test-count 12
```

Следующий обязательный этап перед физиками: приватный прогон на H50Z, стратифицированный просмотр кандидатов и пропусков, *малый* экспертный аудит с классами `candidate track / artifact / unknown` и проверками `same / different / unknown` на независимых физических запусках, в том числе разных камер/плёнок. Нельзя оценивать метод на H50Z только по крестам `start/f1…f8` или сопоставлять их с чужими visualMetro film070 кадрами.
