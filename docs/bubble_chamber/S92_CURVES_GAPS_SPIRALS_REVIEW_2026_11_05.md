# S92 — короткие отметки, «волоски», пунктирные треки и спирали на H50Z

**Ветка:** `feature/bubble-s92-curves-gaps-spirals-2026-11-05` от `research/bubble-chamber-graph-lira`. Исходная исследовательская ветка не перезаписана. Все результаты S72/S85/S86/S87/S88/S89/S90/S91 сохранены.

**Уровень:** новый *read-only* постпроцессор наблюдаемых 2D фрагментов, а не физическая идентификация частиц. Ничего не стирает в исходном BMP, не обновляет бинарную S86-маску, не меняет калибровку и не соединяет физические треки автоматически. Для работы с реальными физическими траекториями нужна экспертиза и независимая разметка.

## 1. Три исправляемые проблемы

**Лишние маленькие штрихи и галочки.** Ранее S86 мог выделять их как обычные фрагменты: порог длины учитывал только размер. S92 оценивает длину по дуге, отношение хорды к дуге, накопленный направленный поворот и максимальный поворот на локальном участке. Короткий штрих, V-образная отметка и компактный U-образный «волосок» попадают в отдельный `LOW_PRIORITY_POSSIBLE_ARTIFACT`. **Это не удаление**: малый настоящий физический трек тоже возможен, поэтому исходные пиксели и `fragment_id` остаются в списке.

**Одна длинная структура, порванная на палочки.** S87 восстанавливает только строго наблюдаемую 8-соседнюю непрерывность на границах тайлов; S77 работал с короткими промежутками и жёстко ограниченными направлениями. S92 предлагает связи между исходно отдельными компонентами при расстоянии до 26 px. Строит **кубическую эрмитову кривую** по двум наблюдаемым концам и их локальным касательным: учитывает поворот при переходе, а не только прямой отрезок. Проверяет альтернативных соседей, занятость концов, циклы и близость других наблюдаемых фрагментов. При конкурирующих продолжениях отказывается от выбора. Любой предложенный промежуток экспортируется отдельным полем `inferred_only_points_xy`; его пиксели **никогда не считаются реально наблюдёнными**.

**Сильно закрученные дуги и спирали.** Форма линии проверяется по накопленному углу изменения касательной (сглаженная, равномерно семплированная по длине кривая). Достаточно длинная линия с большим однонаправленным поворотом помечается `COILING_TRACE_REVIEW` и сохраняется как приоритетная для физика. Компактный «волосок» с большим кратковременным поворотом не тождественен длинной последовательной спирали; S92 применяет разные критерии. После гипотетического соединения фрагментов повторно оценивает форму **отдельно**, с меткой `shape_if_all_gaps_real`.

Ни один из этих критериев **не доказывает, что линия — частица**, не определяет тип частицы и не говорит, что видимая спираль непосредственно создана нейтроном. Нейтральный нейтрон не оставляет собственного заряженного спирального следа; взаимодействие с веществом может породить заряженные вторичные треки, которым нужна отдельная физическая интерпретация.

## 2. Математическая проверка

При дискретном наборе точек `p(s)`, пересемплированных по длине дуги `s`, вводим:

- **Длина** `L = sum_i ||p_(i+1)-p_i||`.
- **Компактность** `r = ||p_last-p_first||/L`, для короткого изгиба мала.
- **Суммарный направленный поворот** `T = sum_i wrap(theta_(i+1)-theta_i)`; численно используем развёрнутый угол касательной после умеренного сглаживания.
- **Согласованность поворота** `C = |T|/sum_i |delta_theta_i|`. При последовательном закручивании близка к 1, при резком зигзаге/зерне падает.

По S92-v1 спиральный кандидат: `L >= 72 px`, `|T| >= 255°`, `C >= 0.72`. Это **предварительный геометрический review-prior**, не оптимизированный на H50Z TEST. Компактный hairpin требует `L <= 72 px`, `|T| >= 115°`, `r <= 0.70` и `C >= 0.55`, если объект не признан закрученной длинной линией.

Для пробела `p_A -> p_B` с внешними локальными направлениями `u_A`, `u_B` строим интерполяцию:

```text
H(t) = (2t³ - 3t² + 1) pA
     + (t³ - 2t² + t) (0.8 d uA)
     + (-2t³ + 3t²) pB
     + (t³ - t²) (-0.8 d uB),    t∈[0,1], d=||pB-pA||.
```

Ограничены расстояние, согласованность направлений, длина и величина поворота моста. **Выбор приоритетной гипотезы не является автоматическим физическим соединением.** Геометрия не гарантирует правильность в местах пересечений, при сильной ионизации и при наложенных проекциях.

## 3. Реальный запуск на новых BMP 405 / 406 / 407

Рабочая ветка:

```bash
git fetch origin
git switch feature/bubble-s92-curves-gaps-spirals-2026-11-05
python -m pip install -r requirements.txt
```

Для каждого исходного BMP сначала получить полностью проверенный S86 (S88 как необучаемый контроль) в приватном каталоге. Значения S88 `0.816/1.7` взяты из *синтетической* CAL, не откалиброваны на реальных физических треках:

```bash
python scripts/research/bubble_chamber/physicists_full_bmp_segmentation.py \
  --bmp /PRIVATE/H50Z/H50Z_030_01_405.bmp \
  --private-out-dir /PRIVATE/results/H50Z_405_S86_S88 \
  --method s88-steerable --s88-low-snr 0.816 --s88-high-snr 1.7 \
  --core 384 --halo 48 --preview-limit 12 --full-mask-npy
```

После успешного завершения S86 вызвать S92:

```bash
python scripts/research/bubble_chamber/physicists_s92_curve_review.py \
  --s86-dir /PRIVATE/results/H50Z_405_S86_S88 \
  --bmp /PRIVATE/H50Z/H50Z_030_01_405.bmp \
  --private-out-dir /PRIVATE/results/H50Z_405_S92 \
  --max-gap 26 --preview-limit 20
```

Открыть локально `/PRIVATE/results/H50Z_405_S92/index.html`. Повторить для `406` и `407` с **теми же параметрами** и отдельными приватными каталогами. Нельзя использовать результаты одного изображения для изменения порога перед оценкой другого, пока не задана роль TRAIN/CAL/TEST. Имена 405/406/407 **не доказывают**, что это независимые физические события; для будущей статистики нужно уточнить, являются ли они стереопроекциями одной экспозиции.

**Если нужен эксперимент именно с оригинальной ANZA:** вместо `--method s88-steerable` запустить S86 с `--method azunet --checkpoint /PRIVATE/REAL_SOURCE_LOCKED_AZUNET.pt`. Без реально обученного, проверенного checkpoint сравнение ANZA с S88/Frangi недопустимо. Для каждого детектора S92 создаёт новый набор гипотез, нельзя переносить чужую калибровку Graph-LIRA.

## 5. Как честно проверить качество

1. Заморозить предикторы S88 и оригинальную AZUNet (если есть реальный checkpoint) **до просмотра экспертных ответов**; на одинаковых кадрах получить кандидаты S86/S92 и baseline S86 без S92.
2. Попросить экспертов оценить *стратифицированную* выборку из четырёх категорий: короткая галочка/волосок, длинная дуга, спираль, предположенный мостик через разрыв; включить случайные контрольные участки, не выбранные S92.
3. Раздельно измерять `track-like/artifact-like/undecidable`, `same-track/different-track/undecidable`; физическая правильность предполагаемого моста не равна отсутствию противоречия геометрии.
4. Сравнить фильтр «показывать только extended/coiling» и полные S86-кандидаты по полноте **подтверждённых** коротких и длинных треков, риску скрытия настоящих коротких частиц, recall разорванных трасс и ложным соединениям.
5. Отложить настоящие независимые физические экспозиции для TEST; не считать три стереоракурса независимыми событиями. Финальные пороги подобрать только на отдельном CAL и закрепить SHA.

**Никаких численных результатов на реальных 405–407 эта документация не утверждает.** До оценки экспертами S92 — инженерно проверенный исследовательский компонент, а не сертифицированное распознавание треков.
