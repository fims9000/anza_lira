# S79 — сохраняемые альтернативы машинных соединений: отрицательный результат

**Дата:** 26 октября 2026. **Эксперимент:** `ANZA-LIRA-BC-S79-20261026`. **Ветка:** `research/bubble-chamber-graph-lira`. **Решение:** не переводить в основной режим.

## Что реализовано

S79 сохраняет все оригинальные 2D-линии и исходные S56 гипотезы. Для потенциальных пиксельно подтверждённых S77 коротких разрывов строится отдельное происхождение кандидата. Ограничения графового решателя: один стык на порт, один вариант на пару линий, запрет циклов и отказ при конфликте или ошибке MILP. Конечные идентичности частиц при этом НЕ известны.

## Данные и научная строгость

- 145 полных кадров film-070 visualMetro, фиксированный whole-frame split **79 TRAIN / 30 CAL / 36 TEST**. Их операторская геометрия НЕ соответствует физическим H50Z-событиям.
- 39 настоящих H50Z фотокропов из **двух фотографий одного физического запуска** предоставляют фон для искусственно добавленных линий. Независимых native физических GT-соединений **0**.
- 32 свежих синтетических CAL-сцены, затем **96 независимых синтетических TEST-сцен**. Для каждой тестовой сцены рассматриваются чистые пиксели и уровни размытия σ=1,1 / σ=1,6, одинаковые для сравниваемых arms.
- Признаки источников, метки правильных искусственных соседей и синтетические source-полилинии не передаются в инференс. Только отдельный исправленный оценщик S69 вычисляет корректность *после* замораживания машинных предсказаний.
- Идентичность исходных S72 алгоритмов, source-cal скорера и сплита подтверждается контрольными суммами до CAL и TEST.

## Интерпретация

**Пиксельно поддержанный возврат S59-отсеянных кандидатов не улучшил правильные соединения.** В clean TEST строгий вариант добавил один, а мягкий два неверных/несопоставленных с искусственным GT стыка при неизменном числе правильных. При размытии граф не изменился. Это не подтверждает физические связи и не допускает продвижение в основной режим.

**CAL заранее выбрала `baseline` для обоих направлений**, ещё до открытия TEST. Контроль повторного запуска TEST дал байтово идентичный JSON, а scene-paired bootstrap интервалы приведены внутри агрегированных файлов. Результаты одного запуска фотографий не дают доверительного интервала для переносимости на другую физическую камеру или сеанс.

Дополнительный native smoke использовал строго одну центрированную 192×192 область на каждом из 39 реальных H50Z-кропов. Базовый метод выдал **83 машинные линии и 3 гипотезы графовых соединений UNKNOWN**; оба экспериментальных подхода не изменили число выбранных native соединений. Это не является ни доказательством точности распознавания, ни физической идентичностью частиц.
