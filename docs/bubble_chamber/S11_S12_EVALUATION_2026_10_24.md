# S11–S12: Orientation-constrained ANZA for bubble-chamber track masks

Date: 24 October 2026. Research branch: `research/bubble-chamber-graph-lira`.

## Scientific target and evidence boundary

Goal: improve segmentation of **thin charged-track traces**, continuity through interference, and suitability for geometry reconstruction, without unsafe joining of unrelated particles. The measured visualMetro dataset contains 145 validated frames of **one** film (070), 1,073 expert-measured tracks and 17,321 3D coordinates, linked to three sets of 2D clicks. **No paired authentic BMPs or expert dense pixel masks for film 070 are available.** All images and binary masks in supervised S11/S12 training/test were **generated** from real measured clicked shapes. Neither model is certified for real hydrogen/propanе transfer.

Original model source files were preserved unmodified: `models/azconv.py` blob `f4217ada00024927506fa8ebe520aa1f68ae5854`, `models/segmentation.py` blob `0b971c117f3d56cc588ebade6991c65faceb8a2a`. Source verified before training. All models saved `last.pt`, `best.pt`, `best_final.pt` weights, validation-calibrated thresholds, data fingerprints and exact parameter settings.

S10 benchmark was not favorable to original AZUNet: with fixed source frame split and 3 initializations, clean synthetic Dice means ordinary U-Net **0.6910** versus AZ **0.6493**; high noise U-Net **0.4153** versus AZ **0.4122**.

## S11 (data seed 20261024): adding differentiable clDice and native AZ axis-alignment loss

S11 compared matched ordinary U-Net and original AZUNet, with original BCE+Dice, additional soft-skeleton clDice (weight 0.2), and original `axis_alignment_loss` (weight 0.05) in 3 model seeds (`20261024`, `20261025`, `20261026`). 8 epochs, batch size 4, widths `(4,6,8,12)`, 2 AZ rules, original residual AZ option, identical train-time noise. 120 training samples / 26 validation samples / 25 test samples from frame-disjoint groups. All model thresholds selected on validation only.

### S11 measured-shape synthetic images: **negative result**

| Arm | Mean clean Dice | Mean stressed Dice | Mean stressed clDice |
|---|---:|---:|---:|
| Standard U-Net | 0.6832 | 0.4033 | 0.3900 |
| U-Net + clDice | 0.5926 | 0.3743 | 0.3735 |
| Original AZUNet | 0.6515 | **0.4100** | **0.3768** |
| AZUNet + clDice | 0.6508 | 0.3262 | 0.3011 |
| AZUNet + clDice + original axis loss | 0.5956 | 0.4071 | 0.3667 |

A paired whole-frame bootstrap across 3 saved seeds found the stressed micro-Dice difference AZ+clDice minus original AZ **−0.0667** (95% conditional CI **[−0.0975; −0.0362]**). Thus large clDice weight is **not** recommended. The native axis loss partially recovers quality but does not clearly surpass AZ baseline.

### Diagnostic problem behind S11

On the same model/batch original AZ's `axis_alignment_loss` provided geometry-field gradient norm about `0.000136`, compared to `0.0725` from the base segmentation loss. Therefore the *original* loss weakly adjusts `geometry_conv` on these narrow generated tracks. This is a **local training gradient diagnostic**, not physical evidence.

## S12 (data seed 20261027): directly learning local tangent fields

S12 adds `bubble_chamber/s12_orientation_field.py`: computes GT line tangents from a structure tensor, represents directions by double angles (sign invariance), and directly penalizes differences between supervised line orientation and the original `AZConv2d` live rule-angle mixtures. It does not edit AZConv kernel. Separate axis and optional light soft clDice (0.05) are tested against independent U-Net, pure AZ, and U-Net+small clDice. 3 model seeds, one fixed new frame split, 8 epochs, 120/26/25 examples. **This is still post-hoc research within the same film.**

### S12 results (three independently initialized models; same test frames)

| Model | Mean clean Dice | Mean synthetic-noise Dice |
|---|---:|---:|
| U-Net | 0.6419 | 0.4575 |
| U-Net + 0.05 clDice | **0.6586** | 0.4490 |
| Original AZUNet | 0.6456 | 0.4712 |
| Original AZ + direct tangent loss 0.05 | 0.6503 | 0.4636 |
| Original AZ + direct tangent 0.05 + clDice 0.05 | 0.6349 | **0.4726** |

All mean values above are descriptive. Paired bootstrapping 25 **whole source frames**, keeping three trained models together, gives the following pooled micro-Dice differences:

- Clean, AZ + direct tangent vs AZ baseline: **+0.0087**, conditional CI **[+0.0017; +0.0156]**. Small improvement on generated clean data.
- Stressed, AZ + direct tangent vs AZ baseline: **−0.0119**, conditional CI **[−0.0256; +0.00002]**. No robust improvement.
- Stressed, AZ + direct tangent + clDice vs AZ baseline: **+0.0006**, CI **[−0.0157; +0.0146]**. Inconclusive.
- Stressed, AZ + direct tangent + clDice vs U-Net: **+0.0287**, CI **[−0.0083; +0.0622]**. Inconclusive.

The reference-axis diagnostic indicates the direct objective produces **substantially larger geometry gradients** (about `0.166` compared with `0.000136` native axis loss). However, the measured held-out **orientation alignment scores did not improve consistently** over AZ baseline at weight 0.05. Gradient size alone is **not** a performance claim. More effective mixing/gating and physically relevant graph objectives need testing.

## S12 downstream geometrical usefulness

`bubble_chamber/s12_curve_geometry.py` takes each *predicted binary mask alone*, skeletonizes the largest component, uses PCA to create an invertible local reference system, fits a quadratic `v(u)=au^2+bu+c`, returns two projected endpoints and curvature in **inverse pixels** with RMS residual. **Only an intact single connected, sufficiently long, near-quadratic mask is accepted for human review.** Disconnected masks return `disconnected_requires_lira` and **are never auto-joined**, since false links are more damaging than abstention.

On frozen held-out S12 masks across 3 seeds, the numbers of accepted 2-D quadratic fits out of 75 test images (25 frames × 3 seeds) are:

| Model | Clean accepted | Noise accepted |
|---|---:|---:|
| U-Net | **55/75** | 5/75 |
| Original AZ | 47/75 | 4/75 |
| AZ + direct tangent | 52/75 | 2/75 |
| AZ + direct tangent + clDice | 52/75 | 3/75 |

Most noisy outputs are fragmented. Endpoint and curvature errors are reported **only for accepted predicted/reference pairs** and are heavily affected by selection: it would be misleading to quote a tiny error when nearly all traces were rejected. Those fitted 2-D image parabolas are **not** physical 3-D trajectories. Physical mass/momentum inference requires the separate, calibrated three-view optical geometry, fiducials, magnetic field and validity conditions discussed by Belяev, not arbitrary curvature-to-mass conversion.

## Present conclusion

1. Strong engineering progress: reproducible training on **the genuine original ANZA source**, exact 3-seed benchmarks, better AZ geometry gradient, safe curvature/parabola review, and negative-case tracking.
2. Scientific evidence does **not** yet support a stable, large gain over conventional segmentation, especially not on authentic images. S11's strong clDice loss was a failure. S12's direct angle supervision is a minor improvement only for clean synthetic pixel Dice; under noise it did not help reliably.
3. Next tested architecture: **S13 hybrid ANZA-guided U-Net**, where original AZConv provides a bounded, learnable small additional image cue to the ordinary U-Net. Compare with a matched ordinary-convolution guidance branch; do not attribute additional model capacity to ANZA geometry.
4. Final acceptance requires expert-reviewed real pixel and instance masks, multi-film/run/medium evaluation, explicit false-bridge rate and downstream visualMetro geometrical reconstruction. Existing real H50Z keypoint labels cannot be silently treated as complete track masks.
