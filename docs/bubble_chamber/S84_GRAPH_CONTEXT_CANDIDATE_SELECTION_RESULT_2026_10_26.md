# S84 — pixel-line evidence + frozen graph context: CAL-only partial gain, fresh TEST fails no-error gate

**Дата:** 26 октября 2026 · **ID:** `ANZA-LIRA-BC-S84-20261026` · **статус:** выбор по CAL не переносится на независимые искусственные сцены; основной S72 НЕ заменять.

## Задача

Проверить, можно ли отсечь дополнительные ложные 2D-фрагменты, учитывая не только их локальную фотометрию, но и влияние на предсказания геометрической графовой модели. S80/S83 генератор дополнительных пиксельных линий, исправленный S69 оценщик, S76 диагностика формы/концов, S72 направление-зависимый исходный конвейер и S56 оптимизатор остаются неизменны. Новые линии — гипотезы, а не подтверждённые частицы.

## Протокол (заморожен до CAL и TEST)

Файл `S84_FROZEN_GRAPH_CONTEXT_EXTRA_INSTANCES_2026_10_26.md`. 145 кадров visualMetro плёнки **070**, разделённых по целым кадрам 79/30/36 TRAIN/CAL/TEST. Геометрия 070 **не совпадает с реальными событиями H50Z**. Два изображения H50Z (`005`,`006`) относятся к одному физическому запуску, 39 приватных 512×512 кропов.

На SOURCE CAL: 24 новых сцены на направление (seed 20268401/20268411), состояния clean и Gaussian blur σ=1,1. Выбор порога q25/q40 по *пикселям CAL*, с контрольной корректностью синтетических стыков только после полного предсказания.

На NEW TEST: 20268403/04 и 20268413/14, 24 сцены каждый = **96 новых синтетических сцен на условие**, clean, blur σ=1,1 и blur σ=1,6. Синтетический эталон недоступен алгоритму инференса, используется лишь для оценки. Сохранены отдельные парные bootstrap CI (1200 пересэмплирований на уровне целых синтетических сцен).

Это нарушает требование не увеличивать неверные/неподтверждённые предложения. Тест не использовался для смены выбора. **Ни один метод не разрешён к автоматическому соединению реальных частиц.**

### Дополнительные фрагменты: контроль формы

На TEST при σ=1,1 фотометрический фильтр принял **40** дополнительных линий, из них по строгому S76 сопоставлено с искусственными истинными фрагментами **9**, с искусственными ложными — **8**. Остальные не получили достаточной идентификации по форме или были неоднозначны. Графовый одноконтактный отбор принял **5** линий и показал **2** условно правильных по форме, **0** синтетически ложных. Более строгий двухконтактный отбор при σ=1,1 не принял ни одного кандидата; нулевое число ложных не означает успех распознавания.

## Вывод и дальнейшая работа

- Сочетание фотометрии и графовых признаков сокращает количество кандидатов, но может отвергать полезные линии. Нужна независимая калибровка trade-off и дополнительные физические запуски с честным GT.
- Достигнут **воспроизводимый отрицательный/ограничивающий результат** для S84. Исторические тесты S80–S83 не использованы для настройки численных порогов S84.
- До подтверждения на новом физическом запуске/экспертной разметке не утверждать восстановление физических треков, 3D или кинематики.
