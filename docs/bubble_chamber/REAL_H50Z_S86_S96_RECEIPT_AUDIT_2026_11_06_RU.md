# Аудит реальных сохранённых результатов ANZA-LIRA на H50Z

Скрипт проверяет реальные **файлы результатов** S86 → S92 → S95 → S96, а не копирует цифры из переписки и не выдаёт синтетические CI-тесты за исследование физических снимков.

## Что уже установлено

Исходные `H50Z_030_01_405.bmp`, `406.bmp`, `407.bmp` прикреплены к разговору ChatGPT. В предыдущем сеансе для 405 сообщались значения 21 266 первичных фрагментов, 20 873 компонентов, 7 769 кандидатов S92, 5 213 предложений и 886 узлов S96. **Эти цифры в этой ветке не подтверждены первичными отчётами.** Не следует использовать их в статье/отчёте без проверки SHA-цепочки и исходных NDJSON. GitHub Actions содержит только синтетические тестовые данные; настоящий BMP и операторские метки туда не передаются.

Прежде чем заявлять реальные численные результаты, необходимо получить **сохранённую приватную структуру каталогов**:

- `S86/manifest.json`, все `S86/records/*.json`, `S86/masks/*.png`;
- `S92/report.json`, `S92/observed_shape_review.ndjson`, `S92/gap_proposals_unknown.ndjson`;
- `S95/report.json`, `S95/all_source_fragment_types.ndjson`;
- если выполнен S96 — `S96/report.json`, `S96/junction_hypotheses.ndjson`, `S96/visual_continuation_pairs_unknown.ndjson`, `S96/original_observed_component_inventory.ndjson`, `S96/review/review_pack.json`.

Скрипт вызывает оригинальный проверенный `_read_source`, повторно проверяя **каждую маску, хеш, размер, фрагмент и его реально наблюдаемые пиксели**. Далее сверяет ID всех наблюдаемых компонентов, количество записей, SHA-цепочку от S86 до S96, типы S95, число узлов/пар S96 и необязательные обзорные фото.

## Запустить на уже сохранённом результате 405

```bash
git fetch origin
git switch feature/bubble-real-h50z-evidence-audit-2026-11-06

python scripts/research/bubble_chamber/physicists_verify_real_h50z_saved_results.py \
  --case '405|/PRIVATE/H50Z405/S86|/PRIVATE/H50Z405/S92|/PRIVATE/H50Z405/S95|/PRIVATE/H50Z405/S96|/PRIVATE/H50Z/H50Z_030_01_405.bmp' \
  --private-out-dir /PRIVATE/results/H50Z405_VERIFIED_AUDIT
```

Пути **примерные** — у существующего пакета от S95 они могут быть `.../S93_SOURCES/S86`, `.../S93_SOURCES/S92`, `.../S95_ALL_OBJECTS`, тогда подставьте именно их. Для S96-отсутствующего результата используйте `-` вместо пути и укажите BMP последним полем.

Для проверки без тяжёлого исходного BMP укажите только четыре пути (S86, S92, S95, при наличии S96). Тогда проверяется сохранённая SHA-цепочка, но не содержимое исходного BMP в байтах, и отчёт это явно показывает.

Повторять `--case` разрешено для 405, 406, 407, только если есть действительно сохранённые независимые S86/S92/S95 выходы каждого кадра. Для каждого фото проверяется отдельный `source_bmp_sha256`; смешивать каталоги нельзя.

Появятся локальные приватные `source_verified_machine_counts.json` и `index.html`. При отсутствии или порче любого обязательного файла инструмент **откажется формировать итоговый отчёт**.

## Если промежуточные результаты потеряны

Потребуется настоящий повторный запуск (не «восстановление» цифр вручную) из доступных BMP:

```bash
python scripts/research/bubble_chamber/physicists_s95_all_classes.py \
  --bmp /PRIVATE/H50Z/H50Z_030_01_405.bmp \
  --method s88-steerable \
  --private-out-dir /PRIVATE/results/H50Z405_REEXECUTION
```

Это создаёт `S93_SOURCES/S86`, `S93_SOURCES/S92` и `S95_ALL_OBJECTS`. S96 после этого запускается отдельно:

```bash
python scripts/research/bubble_chamber/physicists_s96_junctions.py run \
  --s86-dir /PRIVATE/results/H50Z405_REEXECUTION/S93_SOURCES/S86 \
  --s95-dir /PRIVATE/results/H50Z405_REEXECUTION/S95_ALL_OBJECTS \
  --bmp /PRIVATE/H50Z/H50Z_030_01_405.bmp \
  --mask-junction-audit \
  --private-out-dir /PRIVATE/results/H50Z405_REEXECUTION_S96
```

Затем можно выполнить проверку отчётов приведённой выше командой с фактическими каталогами.

**Доказательная граница:** прохождение этих проверок означает **воспроизводимый машинный запуск на конкретной фотографии**, а не экспертно подтверждённые истинные треки. Для научной проверки нужны независимые S97-положительные человеческие линии соответствующего **точно того же кадра**, а затем S98 по полноте и связности. Серию операторских VisualMetro 070 нельзя использовать как соответствующую H50Z 405/406/407 разметку без подтверждённой регистрации.
