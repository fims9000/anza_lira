# Predeclared interoperability source-only benchmark — 2026-10-28

ID: `ANZA-LIRA-BC-S85-INTEROP-20261028`. This comparison is **an artificial component QA benchmark**, not a scientific validation on real bubble-chamber events. No H50Z images, visualMetro film070 measured coordinates or real physics GT are available in the runtime. All backgrounds and synthetic curvature templates are newly generated from explicit public seeds. No model, score, threshold or detector parameter is fit to the held-out scenes.

**Fixed before execution**: 20 synthetic scenes from `SEED=20268588`, scenarios cycling `parallel`, `near_parallel`, `crossing`, `scratched`, `empty_gap`, each under `clean`, `blur_sigma_11`, `scratch_grain`. Two generated 512×512 gray backgrounds, 28 generated sine track templates, 2 true synthetic 3-piece tracks per scene and one injected decoy. Detector candidates limited to 12, minimum 18px segment length and fixed OpenCV LSD/Hough/ridge parameters; score/cutoff `score_geometry_for_QA`, 0.70 with 0.04 ambiguity margin, strict S59 pair gate. Four graph modes: no joins, node-level mutual, greedy per endpoint, original S56 global MILP forest. Candidate GT associations evaluated after all predictions by corrected S69/S76-backed synthetic evaluator. Include **oracle supplied fragments only as a nondeployable upper-bound control**; never use synthetic GT for other detectors or graph scoring.

**Outcomes**: candidate count; shape-matched true injected fragments; correct synthetic joins; noncorrect/unmatched joins; complete 3-piece synthetic paths; solver failures. Paired bootstrap (1000 resamples by synthetic scene) global vs greedy full-chain delta. Note only 20 synthetic scenes/backgrounds and no independently matched real physics GT. This is NOT a fair head-to-head of trained H50Z ANZA-LIRA versus another pretrained network; it is a first controlled examination of detector/solver sensitivity with the **same uncalibrated geometry heuristic** for all detectors. The strength of the result is its falsifiability and interface/extractor compatibility, not superiority evidence.

**No promotion**: the existing S72 main method and S85 pretrained gate are not changed by this benchmark. No real photo, weights or source-measured geometry in the public JSON.
