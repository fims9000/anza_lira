# S42: проверка исходной ANZA без «учителя», видевшего тестовую фотографию

**Дата:** 25.10.2026; репозиторий `fims9000/anza_lira`, только ветка `research/bubble-chamber-graph-lira`. **Статус:** эксперимент выполнен полностью, обе фотодирекции, AZUNet и U-Net, четыре приватных веса модели, два зафиксированных test seed. Модель для реального физического применения не получена.

## Что исправлено после S41

В S39 алгоритм генерировал псевдоположительные маски для фотографии `005` в том числе с помощью AZUNet, обученной на `006`, и наоборот. Если затем учить студента на такой маске и оценивать его на `006`, «тестовый» источник уже косвенно попал в обучающие метки. Эта утечка **не допускается** в S42.

Создан отдельный **классический учитель `geometry_only_pseudo`** — только подлинные пиксели обучающей фотографии, локальная темнота, многомасштабная гессианова кривизна, восстановление полилиний и известные реперные кресты. Он принципиально не читает оценки S31/AZUNet, веса моделей и псевдоположительные маски S39. Метаданные S39 используются только для проверки SHA исходного PNG и координат вырезки. И положительные, и отрицательные машинные псевдометки — предположения, а `255` означает «неизвестно» и игнорируется при обучении.

| Обучающая фотография | Участков 512×512 | Машинных пикселей 1 | Предположительных пикселей 0 | Unknown 255 |
|---|---:|---:|---:|---:|
| 005 | 21 | 37 307 | 193 478 | 5 274 239 |
| 006 | 18 | 27 024 | 145 593 | 4 545 975 |

**Архитектуры:** оригинальные AZUNet и BaselineUNet, параметры архитектур не менялись; ширины `(4,6,8,12)`, у AZ 2 правила. Обе получили **одни и те же** обучающие патчи, batch8, 3 эпохи по 32 шага, AdamW `8×10⁻⁴`, одинаковое квантильное нормирование, сбалансированный BCE только по машинным известным 0/1. Инициализация **одна**: `20261026` — пилот, не статистически подтверждённое преимущество архитектуры.

**Тест:** 24 искусственных сцены на настоящем фоне каждой фотографии, снимки 005/006 одного запуска. Геометрия нарисованных треков взята из независимых по кадрам измерений плёнки 070 (36 кадров test; не участвовали в обучении). Истинная метка относится **только к нанесённой программой линии**, фоновый настоящий физический трек неизвестен. При любом методе берутся лучшие 3,5% пикселей и используется допуск 2 px. В каждой сцене есть заведомо искусственный ложный штрих.

## Главный результат: новую ANZA нельзя объявить лучшим детектором

| Метод | 005→006: нанесённые треки / ложный штрих | 006→005: нанесённые треки / ложный штрих |
|---|---:|---:|
| Локальный контраст | **0.800 / 0.901** | **0.841 / 0.909** |
| Многомасштабный гессианов детектор | **0.817 / 0.831** | **0.822 / 0.891** |
| Обычная U-Net, новый независимый учитель | 0.461 / 0.434 | 0.420 / 0.470 |
| AZUNet, новый независимый учитель | 0.425 / 0.468 | 0.374 / 0.522 |

*Числа — доля точек искусственно нарисованного объекта, где сработал детектор с допуском 2 px. Это **не точность, не полнота и не FPR реальных треков пузырьковой камеры**. Ложный штрих тоже нарисован программой; высокий отклик на него у классических методов — серьёзное ограничение.*

При одинаковом объёме машинного обучения AZUNet уступила U-Net в обоих направлениях, а обе нейросети существенно уступили классическим детекторам по покрытию искусственно внесённых линий. Стабильных данных о преимуществе ANZA нет. Различие между AZUNet и U-Net при одном seed и двух фото не следует объявлять научно статистически доказанным. CI в `S42_PUBLIC_AGGREGATES.json` получены bootstrap только по симулированным сценам и не измеряют перенос на независимую съёмку.

## Решение по алгоритму

1. **Основной генератор кандидатов остаётся классическим многомасштабным гребневым детектором** — он извлекает больше искусственных кривых в фиксированном бюджете, но его неспособность уверенно отклонять искусственные царапины сохраняется.
2. Реперные кресты исключаются из псевдообучения через `unknown` (S41); модель не должна заучивать заведомо служебные X-образные метки как частицы.
3. AZUNet/U-Net сохранены для сравнений и последующих исследований, но **не выдаются за работающий классификатор истинных физических треков**.
4. Следующая практически значимая попытка без ручной разметки: создавать более жёсткие синтетические контрпримеры из реальной текстуры фона, а затем измерять *разность между обнаружением линий и ошибочной активацией царапин* при одинаковом бюджете. Не выбирать метод по тестовым фото; возможна новая независимая съёмка.
5. Физическое 3D и определение массы остаются вне границ задачи без третьей проекции, оптических констант и корректного сопоставления измеренных треков.
