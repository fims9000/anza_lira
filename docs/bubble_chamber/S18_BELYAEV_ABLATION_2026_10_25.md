# S18 | Физические кривые Беляева в малой разметке ANZA–LIRA

**Исследование 25 октября 2026 г. · фиксированная синтетическая проверка · не является оценкой точности на реальных фотографиях.**

## 1. Научный вопрос

Помогают ли математически сгенерированные траектории остановившихся заряженных частиц (адроиды Беляева) обучать оригинальную ANZA распознаванию других форм треков при малом числе положительных/отрицательных меток? И можно ли использовать **неразмеченные** реальные фотографии только для переноса распределения яркости?

Физическая основа: А. В. Беляев, ОИЯИ P1-2023-22, уравнение (9) и ограничения для остановившихся частиц; руководство visualMetro (Беляев, Бушмина, Клевцова, 2025) — структура трёх проекций, реперы и геометрическое восстановление. В S18 физические координаты и измеренные треки используются **только для генерации искусственных изображений**; формула массы/трёхмерная калибровка здесь не проверяется.

## 2. Экспериментальный дизайн

- Один исходный физический источник геометрии: 145 аудированных кадров visualMetro с плёнки `070`; исходные точки реальны, интенсивности изображений, штрихи, разрывы, дефекты и маски симулированы.
- Фиксированное разделение целыми кадрами: 94/26/25 train/val/test; отобрано 120 обучающих картинок, 24 валидационных, 24 тестовых картинки из **13 отдельных исходных кадров**, а также 8 искусственных книжных тестов.
- Обе архитектуры — исходные, неизменённые `AZUNet`/`BaselineUNet`, одинаковые `widths=(4,6,8,12)`, оригинальная AZ использует 2 правила. 12 эпох, batch 8, AdamW 0.0008, одинаковое число шагов и порядок батчей для каждой инициализации.
- Три инициализации 20261024–20261026, одинаковые seed для сравниваемых вариантов. Веса выбирались только по BCE на редких синтетических метках валидации; **порог затем определялся по полной СИНТЕТИЧЕСКОЙ маске валидации**. В реальном few-label режиме такой порог недоступен — это диагностический верхний ориентир.
- Каждый кадр train содержит искусственные положительные/отрицательные точки 0/1/255 и дополнительные 24 отрицательные точки из синтетической известной маски. Неизвестные пиксели не считались фоном. Нигде не использовались экспертные маски настоящих BMP.
- В A используется 120 измеренных форм; в B–E — те же первые 96 измеренных форм + 24 книжные адроиды. Следовательно, это **замена** части измеренных форм на книжные при фиксированном числе изображений, а не добавление к 120 исходным измеренным примерам.

### Варианты фотометрии

- **A**: 120 изображений на формах измеренных треков visualMetro, без книжных траекторий.
- **B**: 96 тех же форм + 24 книжные остановочные кривые, обычный синтетический вид.
- **C**: B с монотонным квантильным преобразованием яркостей 24 книжных train-изображений по 7 неразмеченным H50Z-кропам (2 BMP); метки неизменны, реальные пиксели не стали истинными метками.
- **D**: B с тем же квантильным преобразованием, но эталоны яркости — исключительно синтетические измеренные train-изображения, без доступа к H50Z.
- **E**: B со случайным масштабированием контраста 0,35–0,85 и добавлением шума, без H50Z. **Постфактум сформулированный контроль после первых результатов C**, поэтому только exploratory.

**Строгое ограничение бюджета меток:** при равных 120 кадрах фактически разное число искусственных редких меток: A — 3840 положительных / 5760 отрицательных; B–E — 3672 / 5664. Это небольшая, но реальная потенциальная смешивающая переменная. Все числа ниже относятся к *simulated-label research*, не к настоящей малой экспертной разметке.

## 4. Парная оценка неопределённости

Пересэмплирование инициализаций и **целых исходных кадров** (13 кластеров, 4000 повторов), одинаковые семена и те же тестовые кадры. 95%-й бутстрэп-интервал условен по одной физической плёнке, он не показывает перенос на другие камеры или заливки.

| Сравнение по стрессовому Dice | Средняя разница | Условный 95% интервал |
|---|---:|---:|
| azunet: C_measured_book_photo_style - A_measured_only | +0.1465 | [-0.0064; +0.2552] |
| azunet: E_book_generic_robust_augmentation - A_measured_only | +0.1346 | [-0.0025; +0.3162] |
| azunet: B_measured_plus_book - A_measured_only | -0.0587 | [-0.2019; +0.0760] |
| azunet: H50Z style vs generic robust augmentation | +0.0119 | [-0.1385; +0.1972] |
| azunet minus unet: C_measured_book_photo_style | +0.1289 | [-0.0849; +0.3127] |

**Все указанные интервалы пересекают ноль.** Поэтому улучшение C или E на этих трёх seed нельзя объявлять статистически убедительным, несмотря на положительные средние цифры. Кроме того, поиск варианта E производился после просмотра C, то есть этот дополнительный поиск не был предрегистрационным.

## 5. Реальные H50Z — только диагностический тест переноса

На 7 неразмеченных H50Z-кропах, полученных из 2 BMP, вычислен процент пикселей, которые сети отнесли бы к треку при синтетическом пороге. Фрагменты 512×512 уменьшены до 64×64: тонкие треки при этом могут исчезнуть. В `unlabeled_real_probe.json` присутствуют только **распределения предсказаний**, а не истинные метки и не реальная точность.

## 6. Вывод

1. **Голые книжные спирали B не улучшают перенос на другие синтетические измеренные геометрии**: AZ стресс 0,2664 вместо 0,3250, а U-Net — 0,3741 вместо 0,4766.
2. **Фотометрическая вариативность полезна как кандидат на улучшение ANZA**: C стресс Dice 0,4715, E стресс Dice 0,4597. Но оба метода имеют широкие интервалы, пересекающие ноль. C превосходит E всего на ~0,012; **специфическую пользу H50Z нельзя утверждать**.
3. Лучший стресс Dice среди приведённых средних — **U-Net A = 0,4766**, почти как AZ C = 0,4715. ANZA пока не превосходит сильный базовый метод устойчиво.
4. Непрерывность линий F1 и Dice — не совпадают с правильностью принадлежащих одному треку фрагментов. В S18 **нет экспертной разметки ID отдельных треков на настоящих BMP**, поэтому оценки ложных объединений физически отсутствуют.
5. Метод по книге относится к специальному режиму **остановившейся заряженной частицы** и не должен навязываться всем следам или использоваться для расчёта масс без трёх проекций, поля и оптических констант.

## 7. Следующий проверяемый эксперимент S19

Сделать прицельную экспертизу **небольшого количества реальных BMP-кропов**: несколько точек на треке, несколько надёжных артефактов, и особенно метки «один трек / разные треки» для спорных соединений. Учить ANZA на подтверждённой частичной разметке с аугментациями, Graph-LIRA — на парах фрагментов. Отдельно проверить false join rate и восстановление разрывов длиной 1/3/5 точек на **не участвовавших в обучении реальных снимках**. Книжные кривые использовать только для допустимых остановочных режимов, не как универсальную гипотезу.

**В рамках текущего доступного массива отсутствуют соответствующие экспертные реальные маски и набор трёх проекций одного кадра**, поэтому S18 не может доказать полную автоматизацию реального физического анализа.

## Воспроизведение

```bash
for seed in 20261024 20261025 20261026; do
  python scripts/research/bubble_chamber/s18_book_ablation.py \
    --measurements /PRIVATE/1mH2Data/S1 --out-dir /PRIVATE/results/$seed \
    --seed "$seed" --epochs 12 --batch-size 8 --size 64 \
    --models azunet unet \
    --arms A_measured_only B_measured_plus_book C_measured_book_photo_style D_measured_book_synthetic_style E_book_generic_robust_augmentation \
    --style-crops /PRIVATE/H50Z/crops
done
python scripts/research/bubble_chamber/s18_analyze_results.py \
  --index /PRIVATE/S18_Belyaev_ANZA_Study/index.json --out-dir /PRIVATE/S18_Belyaev_ANZA_Study
```

`index.json` связывает 30 отдельно сохранённых train-checkpoint/metrics/probability-артефактов; файл содержит SHA-256 каждого checkpoint. В архиве исходных пользовательских фотографий и оригинального 1mH2Data **нет**.
