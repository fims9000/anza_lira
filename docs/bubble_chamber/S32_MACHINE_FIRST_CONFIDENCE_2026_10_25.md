# S32 — ANZA–LIRA: исправление обучения на машинной разметке и безопасная ревизия

**Статус:** инженерные функции реализованы; реальная точность физических треков не подтверждена.

## Что было исправлено

В S31 `split_bce(logits,target,weights)` принимала веса слабых меток, но не использовала их. S32 реализует реально взвешенную функцию `confidence_bce` с ограниченной долей слабых отрицательных меток и строгим запретом обучаться на `UNKNOWN=255`. Добавлена одинаковая для обеих архитектур балансировка окон вокруг предложенных положительных линий и отдельно вокруг предположительно отрицательных пикселей. Оригинальные `AZConv2d` и `AZUNet` не изменяются.

## Проверка на исходных H50Z

Обе архитектуры обучались **по двум инициализациям 20261025 и 20261026**, по две эпохи: (1) прежняя невзвешенная функция потерь, (2) новый S32 с коэффициентами доверия. У обоих вариантов одинаковые исходные S31 маски, одинаковое семплирование, одинаковый бюджет и разбиение: H50Z-005 обучение, H50Z-006 оценка согласия с машинными метками. Всё это изображения **одного физического запуска**, а не независимый эксперимент. Модель выбирается по машинному proxy BCE, не по экспертной точности.

Дополнительный тест: 48 *искусственно* нанесённых траекторий и отвлекающих царапин в каждом из двух прогонов на неизменённых фотографических фонах H50Z-006; шаблоны линий происходят из измерений visualMetro, но не зарегистрированы на этой фотографии. AUROC вычислен только на внесённых пикселях.

| Метод | AUROC seed 20261029 | AUROC seed 20261030 |
|---|---:|---:|
| U-Net: прежняя функция (тот же новый бюджет) | 0,578 | 0,603 |
| U-Net: S32 confidence | 0,486 | 0,601 |
| AZUNet: прежняя функция (тот же новый бюджет) | 0,670 | 0,470 |
| AZUNet: S32 confidence | 0,669 | 0,511 |
| Старые веса S31 U-Net (неравный бюджет — справка) | 0,640 | 0,662 |
| Старые веса S31 AZUNet (неравный бюджет — справка) | 0,705 | 0,611 |
| Классический направленный фильтр | 0,564 | 0,564 |

**Результат отрицательный:** взвешенная функция потерь улучшила отдельные значения для AZUNet, но не показала устойчивого преимущества. **Не подменять старые S31 веса новыми как «лучшими»**: такого научного подтверждения нет. Самооценка на машинных масках тоже не равна реальной точности.

## Новый рабочий инструмент

`S32_MACHINE_REVIEWER.html` — полный исходный S31-редактор с 39 реальными участками, 133 гипотезами линий и 28 вопросами о связях. Добавлена очередь неоднозначных линий (дубликаты, несогласованные алгоритмы, реперы, границы изображения, слабая фотометрия) и ранжирование пар по **некалиброванной** геометрической согласованности. Ни одна гипотеза не превращается в экспертную или физическую метку автоматически.

Правки сохраняются в исходный совместимый файл `S31_machine_labels_local_corrections.json`. Новая `s32_relation_bridge.py` принимает только явные решения локального пользователя `LOCAL_SAME_PROVISIONAL` и `LOCAL_DIFFERENT_PROVISIONAL`, оставляет остальные 28 связей неизвестными. Когда нет ответов, обучающих пар **ноль**.

```bash
python scripts/research/bubble_chamber/s31_build_weak_masks.py \
  --drafts /private/S31_MACHINE_DRAFTS.json --tiles /private/photos_H50Z_derived \
  --corrections /private/S31_machine_labels_local_corrections.json \

  --manifest /private/S32_masks_after_corrections/weak_manifest.json \
  --tiles /private/photos_H50Z_derived --out /private/S32_train

python scripts/research/bubble_chamber/s32_compile_local_pairs.py \
  --drafts /private/S31_MACHINE_DRAFTS.json \
  --corrections /private/S31_machine_labels_local_corrections.json \
  --out /private/S32_local_relation_reviews.json
```

**Никакие числа из S32 не должны обозначаться как физический Dice, accuracy частиц или ошибочные реальные соединения.** Для этого требуется точечная проверка настоящих линий и связей физиками и независимый запуск/заливка; модельные черновики отделены от операторских `start` и `fiducial`.
