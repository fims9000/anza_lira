# S91 — проверяемое согласование экспертных оценок и повторный слепой просмотр

**Ветка:** `research/bubble-chamber-graph-lira`. **Статус:** офлайн-инструмент, проверенный на сгенерированных примерах. **Не** валидирован на реальных H50Z.

## Назначение

S86/S88 извлекают машинные линии из исходного BMP; S89 даёт диагностические признаки и приоритет просмотра; S90 создаёт закрытую галерею и проверяет экспортированные мнения независимых рецензентов. S91 обрабатывает **уже проверенные** S90-решения и составляет следующую подборку для независимого просмотра.

Эксперты отмечают только визуальное сходство с треком, сходство с дефектом изображения или невозможность определить. Даже согласие трёх экспертов **не подтверждает идентичность физической частицы, 3D-реконструкцию, `dE/dx`, полную маску или оценку полноты обнаружения реальных треков**. Нельзя автоматически принимать, отклонять, удалять или склеивать машинные линии.

## Приватный запуск

Сначала запустите S90 `verify` с экспортами независимых рецензентов и получите `review_summary.json` + `case_votes.ndjson` в новой приватной папке. Далее:

```bash
python scripts/research/bubble_chamber/physicists_s91_consensus.py \
  --pack-dir /PRIVATE/results/H50Z_005_S90_REVIEW \
  --verified-dir /PRIVATE/results/H50Z_005_S90_VERIFIED \
  --s89-dir /PRIVATE/results/H50Z_005_S89_AUDIT \
  --private-out-dir /PRIVATE/results/H50Z_005_S91_CONSENSUS \
  --max-followup-cases 24
```

S91 **не нужен** исходный полный BMP или загруженная сеть: он использует только исходные S90-превью (настоящие пиксели остаются строго приватными) и S89-манифест. Проверяются SHA-256 S90-пакета, входов S89, исходного BMP, S86-манифеста, каждого исходного и размеченного превью. Независимо пересчитываются все статусы из индивидуальных голосов S90: подмена, дубликат, некорректное решение или изменение исходных файлов приводит к отказу **до записи результата**.

В результате создаются закрытые файлы:

- `report.json` — полнота просмотра, распределение *только выбранных* кандидатов по приоритетам S89, доля несовпадений и неопределённых ответов, парное совпадение рецензентов на **пересекающихся** случаях и описательный коэффициент Коэна κ там, где он определён. Коэффициент не вычисляется при малом перекрытии или вырожденном единственном классе. Эти числа **не** являются `precision`, `recall`, `F1` физических треков;
- `followup_queue_private.json` — внутренний список причин повторного просмотра: сперва явное несогласие, затем недостаток независимых отзывов. **Не показывать** его следующему рецензенту;
- `followup_blinded/index.html` с `images/*.png` — отдельный локальный интерфейс **только неразрешённых** примеров, без флагов S89, оценок и имён предыдущих экспертов. Если все примеры имеют совпадающие определённые визуальные оценки, интерфейс следующего раунда не создаётся.

Все файлы записываются в новую приватную папку вне публичного Git, Unix-права `0700/0600`. Существующие S86/S89/S90 результаты не модифицируются.

## Как провести следующий раунд

1. Дайте **только** `followup_blinded/index.html` и его папку `images/` новому независимому рецензенту. Не передавайте ему `followup_queue_private.json` или ответы первого раунда.
2. Сохраните скачанный `PRIVATE_S90_<reviewer>_decisions.json` в закрытом каталоге. Экспорт содержит хеш **исходного S90-пакета**, чтобы повторный раунд можно было объединять, не смешивая разные версии фотографии.
3. Запустите **исходный** S90 `verify` на всех независимых JSON (первый, второй, третий...) с **исходным** `--pack-dir`, но новым `--private-out-dir`. Повторно вызовите S91 для обновлённого подтверждённого пакета.

```bash
python scripts/research/bubble_chamber/physicists_s90_review.py verify \
  --pack-dir /PRIVATE/results/H50Z_005_S90_REVIEW \
  --responses /PRIVATE/reviews/first.json /PRIVATE/reviews/second.json /PRIVATE/reviews/third.json \
  --private-out-dir /PRIVATE/results/H50Z_005_S90_VERIFIED_ROUND2
```

S90 отвергает повторную регистрацию одного `reviewer_id` — самостоятельность оценки должна обеспечиваться также организационно. Каждая новая проверка создаёт отдельный закрытый каталог, а не переписывает предыдущее заключение.

## Ограничения выборки

**Выборка S89/S90 заведомо нерепрезентативна**: сначала выбраны тайлы по плотности машинных линий, затем по машинным признакам и ограничениям на число кандидатов в одном тайле. Никакие агрегированные доли `TRACK_LIKE` не допустимо экстраполировать на все частицы или весь H50Z. Cohen κ измеряет согласованность *ответов людей*, а не точность детектора. Даже при формальном κ=1 физические маски по-прежнему отсутствуют.

В тестах используют **только сгенерированный BMP** и фиктивные решения `physicist_01`, `physicist_02` и т.д. Эти идентификаторы — данные теста, а не реальные физики. Доказательная оценка требует независимых физических экспозиций, стереосопоставлений и специально подтверждённых физических эталонов. Исторические S72/S85 не меняются.
