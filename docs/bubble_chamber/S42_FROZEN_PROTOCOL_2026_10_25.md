# S42 preregistration — independent geometry-only pseudo labels, CPU feasibility pilot

Frozen **before** reading S42 test outcomes, 25 October 2026.

- Primary failure to address: S39 pseudo labels for photo 005 used a teacher trained on photo 006, so using them for student training 005→006 would leak test-photo data. **Do not use S39 positive/negative pixels or S31/AZ teacher predictions as student labels.** S42 teacher consists only of `ridge_evidence`, `extract_ridges`, deterministic local contrast/ridge rules and the S40 known-fiducial unknown guard. The S39 JSON may be read for immutable crop SHA and source crop origins but never for machine predictions.
- Sources: 39 SHA-checked real 512×512 H50Z crops, photo 005 (21) and photo 006 (18), same physical run. Two directions trained on exactly one photograph, evaluated on the other; 070 measured tracks from 36 frame-disjoint held-out frame IDs are used only to inject artificial test strokes, not to train the segmentation models.
- Models: pristine original `AZUNet` and equally-sized `BaselineUNet`, widths (4,6,8,12), original 2 AZ rules. Same preprocessing (`quantile`), same batch sequence and optimization, AdamW lr=0.0008, 3 epochs × 32 steps × batch8, seed=20261026. Only 1 seed: **feasibility, not comparative statistical significance**.
- Loss: pseudo positives and pseudo negatives weighted equally within each training batch; ignore unknown pixels completely. No unseen-photo model selection and no oracle GT. Fixed 3.5% top-score image budget and tolerance 2 px. Synthetic evaluation: 24 scenes per test photo (six each parallel/crossing/scratched/empty gap), photo005 seed 20261129, photo006 seed 20261130, each with actual 2 measured-geometry tracks and one artificial decoy scratch.
- Comparators: original AZUNet, U-Net **retrained on same source-pure pseudo teacher** plus **fixed** raw Hessian ridge and local darkness; no hyperparameter tuning on test. Outcomes: injected-track pixel coverage and artificial scratch activation at equal budget; scene-level bootstrap 95% CI with fixed resampling seed. Model weights and overlays private.
- Reject any native physics accuracy, 3D, mass or particle-ID claims. One physical run and no native masks. Negative outcomes must remain visible. Report inability to distinguish scratches if seen; do not re-label simulator scratch as certified real negatives.
