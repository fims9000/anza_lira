# S19 — Обучение ANZA + Graph-LIRA на минимальной экспертной разметке настоящих H50Z

**Статус: инструмент разметки, импортёр, оригинальный обучающий конвейер и контрольные тесты работают; размеченных физиком реальных треков пока нет.**

## Цель

Уйти от оценки одного Dice на полностью синтетических изображениях и построить проверяемую цепочку:

`фотография H50Z → небольшая экспертная разметка 0/1/255 и "один/разные" → оригинальная AZUNet и обычная U-Net при одинаковом бюджете → Graph-LIRA (если ≥10 подтверждённых связей двух классов) → предложения для новой фотографии → отказ от физического вывода, если нет независимой калибровки`.

Система не должна требовать постоянного ручного измерения каждой новой плёнки, но должна уметь **воздержаться от уверенного решения** при неизвестных условиях. Нельзя заранее утверждать, что достигнута соответствующая точность.

## Что есть из реальных данных

- 2 исходные BMP `H50Z_030_01_005.bmp`, `H50Z_030_01_006.bmp`, обе из **одного физического запуска**; 7 подизображений 512×512 около `start`.
- Frangi автоматически предложил 37 фрагментов; они **не размечены экспертом** и не используются как положительная или отрицательная истина.
- `start` — координата от исходного приложения, а не подтверждённая линия или идентичность частицы. Метки `f1`–`f8` — возможные реперы, а не разметка треков.
- Нет проверенных попиксельных масок, подтверждённых связей между фрагментами, отдельной плёнки из другой заливки, полного стереонабора или карты магнитного поля.

## Экспертный путь, минимальные решения

1. Откройте `S19_review_workbench.html` — это локальная страница, фотографии встроены, внешние запросы отсутствуют.
2. Перейдите по семи фрагментам. Выберите предложенную линию Frangi и нажмите «Это трек» или «Это артефакт». Неизвестные оставляйте неизвестными.
3. Если алгоритм упустил видимую линию, выберите «Дорисовать трек» и проведите по ней курсором/пальцем. Аналогично можно обозначить **достоверный** артефакт. Разметить целый фон не требуется.
4. Если два **подтверждённых** фрагмента принадлежат одной частице, отметьте `A` и `Б`, затем «Одна частица». Если точно разные — «Разные треки». Если не уверены, выберите «Не уверен».
5. Нажмите «Скачать экспертные решения JSON». Можно импортировать JSON позже и продолжить. Пришлите этот JSON для обучения. **Не подменяйте его автоматическими предложениями Frangi/ANZA.**

Небольшой начальный пилот целесообразно распределить между обеими BMP: несколько подтверждённых трековых и артефактных отрезков для обучения на `005` и проверки на `006`; для Graph-LIRA нужна хотя бы небольшая смесь подтверждённых «один трек» / «разные треки» (технический минимум классификатора — 10 ответов). Количество 10 — порог обучения программы, **не доказательство достаточности разметки для промышленного качества**.

## Воспроизведение: стадия без экспертов

Запустить из корня исходного репозитория с уже подготовленным `proposals.json` и исходными PNG:

```bash
python scripts/research/bubble_chamber/s19_real_photo_review.py \
  --proposals /private/h50z_review_cli/proposals.json \
  --images /private/h50z_review_cli \
  --out-dir /private/s19_review_bundle
```

Сразу после этой команды `S19_readiness.json` обязан содержать **нулевые** реальные подтверждения, все маски неизвестны, обучение на настоящих фотографиях **не запускается**.

## После возвращения настоящих экспертных решений

```bash
python scripts/research/bubble_chamber/s19_real_photo_review.py \
  --proposals /private/h50z_review_cli/proposals.json \
  --images /private/h50z_review_cli \
  --reviews-json /private/S19_H50Z_expert_reviews.json \
  --out-dir /private/s19_verified

python scripts/research/bubble_chamber/s19_run_small_label_pipeline.py \
  --proposals /private/h50z_review_cli/proposals.json \
  --images /private/h50z_review_cli \
  --expert-review-json /private/S19_H50Z_expert_reviews.json \
  --out-dir /private/s19_train --epochs 4 --patch-size 128
```

Компилятор проверит исходные SHA-256 и координаты, преобразует только решения человека в маску `0` = артефакт, `1` = трек, `255` = неизвестно. Перекрывающиеся противоречивые метки превращаются обратно в `255`. Для Graph-LIRA получаются только подтверждённые ответы «одна» / «разные», и автоматически выбираемая ориентация концов **не считается физически установленной**.

Если оба исходных BMP имеют достаточно меток обоих классов, только из подтверждённых пикселей выбираются не более четырёх 128×128 окон на исходный фрагмент. Маска копируется без интерполяции (`255` остаётся `255`), кадры не перемешиваются между обучением и валидацией. Число окон НЕ равно числу независимых экспертных ответов. Запустятся исходные AZUNet и U-Net на одинаковом бюджете; порог выбирается по валидации и оценивается **только BCE по подтверждённым пикселям** (не полный Dice). При менее чем 10 проверенных пар Graph-LIRA **воздерживается** от обучения. При достаточном количестве пар модель остаётся **только предварительной**, пока не будет подтверждения на независимом запуске.

## Что именно проверено сейчас

- Все семь реальных PNG привязаны к исходной BMP через ROI, SHA-256 и версию Frangi.
- Генератор HTML/JS прошёл запуск в headless Chromium: переключение по кадрам, подтверждение линии, рисование отсутствующего артефакта, экспорт JSON и импорт сохранённых решений — без ошибок JS. Экспертные метки с настоящих фото **при тестировании не сохранялись**.
- На искусственных тестовых фотографиях проверены маски, локальные окна вокруг подтверждённых меток, конфликт меток, подмена файлов, отсутствие ложных отрицательных меток, подготовка меток связности, попытка запуска без разметки, предварительное обучение обеих оригинальных архитектур с источниками Git SHA.
- Допускается распределять положительные и отрицательные экспертные пиксели **по разным обучающим фрагментам**, но не добавлять неизвестный фон в качестве отрицательной категории.
- Численная точность на настоящих BMP и вероятность ложного объединения реальных частиц: **неизвестны**.

## Независимая физическая проверка

В текущем H50Z только две фотографии одного запуска, поэтому валидироваться по второй можно лишь как внутрисерийную проверку с возможной корреляцией. Перед заявлением «автоматически без человека» нужны: иная плёнка/запуск, экспертно проверенные идентичности треков, калибровка проекций/реперов, версия карты магнитного поля и внятная частота ложных соединений.

**Не выпускать физические массы, импульсы, заряды или уверенные соединения на основании одной синтетической оценки.**
