# CRACKS V26 — real-image end-to-end predicted-port ANZA→SBPP→LIRA pilot

**Registered 14 November 2026. Exploratory redesign following fully inspected CRACKS V17–V22 and synthetic V23–V25; not an untouched confirmation or the original historical checkpoints.** Branch \`research/tver-v26-predicted-cracks-e2e-20261114\`.

## Goal / definition of an end-to-end result
Train a **new** \`models.segmentation_v2.build_comparable_model("anza_v1")\` (genuine AZConv encoder), and a label-budget/parameter-width-matched **"unet"** on exactly the same real expert CRACKS v2 TRAIN seismic sections. Freeze their checkpoint SHA and segmentation thresholds on disjoint CAL sections. Then, on section-disjoint TEST sections, run (a) segmentation **image→predicted probabilities**, (b) **SBPP V3-B** soft/hard branch extraction and endpoint candidate proposal derived **only from predicted probability and image**, (c) an explicitly **new V26-LIRA** relation scorer fitted using predicted TRAIN candidates and TRAIN expert-supervised artificial gap interventions, with frozen CAL selective decision rule, and (d) deterministic widest/straight path. Report per-stage attrition and distinct failure reasons; do not claim the historical ANZA→SBPP→LIRA learned weights were recovered.

## Source and split contract
- Source: official CRACKS v2 Zenodo record \`13926822\`, image ZIP MD5 \`6557236191763af7bd8298ecb136d41e\`, expert segmentation ZIP MD5 \`01e1697e886da2079ff3c1967334a7ca\`. Files stay in runner storage; never commit raw images.
- Spatial group = \`section_id // 50\`, where section IDs are the real F3 inline indices and not row indices. Train groups \`{0,1,2,3,4}\`, CAL group \`{5}\`, buffer \`{6}\`, TEST group \`{7}\`. Only cases with an official expert mask contribute supervised label/metric. Also use all TRAIN images if desired without TEST labels, but do not use test image data for optimization. The buffer is a 50-section spatial separation from CAL to TEST.
- TEST source images may be decoded for inference only *after all segmentation and V26-LIRA weights/thresholds are frozen*. TEST expert masks are only decoded to select artificial intervention boxes and calculate performance; these intervention locations are presented to inference only as **known artificially erased rectangles**. Expert true endpoints, individual trace ID, hidden centerline, GT pair label are NEVER input to ANZA, SBPP, LIRA or path selection.
- The original expert labels BLUE=confident fault, GREEN=uncertain, ORANGE=verified nonfault, WHITE=unknown/unlabeled. Do not silently turn white into ground-truth nonfault. Any sampled white-background pseudo-negative for segmentation is **assumed/background-mining supervision** with explicit label-noise caveat and recorded fraction. For test segmentation report coverage/recall of marked blue and optional precision over verified BLUE/ORANGE only; unknown white is excluded from physical pixel accuracy denominators.
- Intervention: select at most 2 long, unbranched expert blue traces per section by fixed path ordering, remove a fixed 12-point around-midpoint rectangle **from the predicted ANZA segmentation probability**, not from the observed seismic image. This constructs one controlled LINK world. Construct an additional **synthetic candidate-absent NO_LINK world** by suppressing a destination-side neighborhood from predicted probability using the known intervention specification; this is NOT a natural geological negative. All evaluation is conditional on an expert-selected intervention region, not free-form detection of unknown gaps in a seismic volume.
- Source ports are chosen from SBPP-visible *predicted* ports near the known erased rectangle, WITHOUT querying the expert oracle endpoint. Candidate locations are proposed from predicted hard and soft branch clusters, not expert lines. All candidate attributes are measured from predicted mask and observed seismic only.
- Comparator: same-size/steps/convolution topology U-Net trained on exactly the same TRAIN patches, with the identical SBPP + relation-score training schedule and CAL policy. Also stage-wise \`SBPP geometry-only\` and deterministic \`straight-line\` path; do not compare test metrics to published 3D segmentation networks without re-running them on the same task.

## Fitted models and calibrated controls
- ANZA-v1 = actual repo ComparableStructuralUNet AZConv variant; control = exact same U-Net macro structure with normal 3x3 conv; widths (4,8,12,16), 3 channels, sigmoid visible logits. New weights seeded 20262611/20262612, not historical ANZA. Patch 64x64, balanced train-only positive-patch selection, 120 optimizer steps AdamW lr .002, batch1, deterministic order and same label budget; no pretrained weights.
- Loss: sample-specific masked weighted BCE on confident BLUE pixels and reliably annotated ORANGE, plus explicit weak assumed negatives sampled ≥12px away from any BLUE/GREEN trace (only to make fitting feasible if ORANGE sparse). Record pseudo-negative ratio; train both models same masks. Segmentation threshold chosen by CAL only from \`{.2,.3,.4,.5,.6,.7}\`; if no positive predicted or no valid labels, report STOP. TEST must not select architecture or threshold.
- LIRA-V26 uses an explicit *new fitted* sklearn logistic relation head with predicted source/candidate geometric and pixel features (same feature family for both segmentation frontends), TRAIN labeled matched pairs from TRAIN expert-defined gap interventions only. Must have >=4 positive and >=4 negative candidate training pairs, else \`STOP_INSUFFICIENT_RELATION_DATA\`; **no oracle candidate injection**. Select a single CAL-only decision threshold maximizing correct accepted LINK (with <=10% empirical false accepts on candidate-absent synthetic NO_LINK), otherwise abstain. CAL sample sizes and exact risk denominator reported. No claim of 2% geological false-positive control from a tiny CAL.
- Path routine sees only accepted predicted endpoints and observed predicted/real image; compare deterministic straight bridge vs maximin where available, and report true GT hidden centerline tolerance 2 only after decision. A correct accepted source↔destination pair must align both endpoints with original expert trace endpoints within 8px *regardless of their order*. If no candidates exist, do not assign a synthetic accuracy of 100%.
- Primary report for each frontend: number of real TEST expert sections and controlled gaps; predicted segmentation pixel recall on confident expert blue; fraction with >=1 source port near gap; >=1 correct proposed pair; correctly accepted positive / all positive; wrong accepted branch / all positive; false accepted / synthetic NO_LINK; bridge accuracy tolerance2 conditional on correct accepted pair, and total real-data image→mask→proposal→decision→path recovery / all gaps. Report geometry-only baseline on SAME proposals and same threshold CAL budget.
- No automatic joining real faults on image, no write to CRACKS or original model files; all outputs are read-only research artifacts on a new branch.

## Stop and interpretation
A missing input, training failure, degenerate all-positive segmentation, empty positive learned relation examples, data leakage or insufficient expert TEST links must STOP with explicit denominator and an immutable failure receipt. Report unlearned, absent and failed stages separately. A successful synthetic intervention E2E pilot is a **different, newly trained model**, not a replicated historical ANZA-LIRA or natural geological state-of-the-art claim. Real disconnected expert components have no validated cross-instance fault labels, so they cannot be used as known geological negatives.
