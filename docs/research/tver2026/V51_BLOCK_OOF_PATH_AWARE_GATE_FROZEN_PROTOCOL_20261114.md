# V51 — source-block-out-of-fold path-aware selective linker (posthoc real Thebe)

**Protocol frozen on 14 November 2026 before V51 evaluation.** This is an exploratory experiment on repeatedly inspected Thebe VAL1 40..99, one field with unknown inter-section correlation. No independent external TEST7 access. V50 path-net outcomes are not used to choose this feature set, architecture or hyperparameters.

## Reason for architectural change
Earlier V45 OOF scene-level accept/refuse gate predicts whether *top1 is the correct pair*, not whether the **decoded line is accurate**. This is insufficient when V47/V49 actual 2px geometric path success is only 2–3/120 even though pair rank is 45/120. The V50 learned path stage is trained with true centerline targets in TRAIN1 and may improve physical shape but its acceptance policy still ignores path quality.

## Complete two-target architecture
- Frozen source frontend: same original V33 trained ANZA SHA, candidate q70 dense-only rescue (fixed 48 slots), V40 symmetric pairwise Logistic ranker and V50 seven-channel learned conditional path CNN followed by ribbon DP. All network targets are computed from TRAIN1 expert hidden centerline only.
- Ranker and pathway model each trained on TRAIN1 groups only; no leakage from target source group into either pathway or pair ranking scores used as acceptance-gate TRAIN features. Use **five contiguous source-section holdout blocks** of exactly 20 source sections each: heldout indices 0..19,20..39,40..59,60..79,80..99. For each block, fit both pathway model and pairwise ranker on remaining 80 source sections (path model 25 fixed epochs), then score the 20 heldout source sections' 40 LINK/NO_LINK controlled gaps. These are _within-field_ source-block OOF, not verified independent physical blocks; boundary-adjacent sections may still share geology.
- Gate TRAIN label is **1 only if** top1 predicted source/target is the 8px-correct LINK continuation AND V50 learned path constructed from observed input meets the original hidden-centerline metric (2px tolerance; both pixel precision and recall >=80%). All other LINK cases plus synthetic NO_LINK cases have label0.
- Gate input = original 13 V45 observed scene features plus 6 predeclared path-only observed descriptors: learned heatmap probability along the decoded route within the gap (mean, lower 20% quantile); learned heatmap probability contrast of decoded route vs whole erased rectangle; path length / predicted chord distance; mean spatial offset from predicted chord within erased rectangle; fraction of path pixels within erased rectangle. No truth, hidden geometry, group IDs or synthetic world label enter gate features. Empty candidate list -> all path descriptors zero; fail-closed.
- New gate = TRAIN OOF StandardScaler+LogisticRegression(`C=.3, class_weight=balanced,max_iter=1400, random_state=20261114`). If fewer than 8 OOF successes exist, report inability to train gate and **do not** fit/trust a degenerate classifier or weaken criteria; V50's unchanged ranker/gate remains scientific baseline.
- Fit final V50 path model on all 100 TRAIN1 sections and final ranker on the same TRAIN1 predicted pair labels. Predict the exact existing 120 LINK +120 synthetic NO_LINK previously seen VAL1 relation-CAL cases. Do not use VAL labels for fitting or selecting score thresholds.
- Frozen original V45 list of 11 accept thresholds, and simultaneous one-sided exact CP (95% Bonferroni across 11 thresholds × 2 source-level error families). Here **wrong LINK** means any accepted wrong pair OR accepted path with insufficient pixel accuracy; **false NO_LINK** means accepted synthetic absent-target case. This is stricter *path-aware* risk than previous pair-only gate. Also report all-threshold descriptive empirical <=10% source rate and true accepted paths; do not promote selected CAL thresholds to deployment.
- The report compares V45 original pair-only OOF gate, V50 actual shape counts and V51 path-aware OOF gate on the identical full cases. It explicitly reports correctly ranked pair, decoded path correct conditional on pair, accepted correct path, false accepted LINK path, accepted synthetic NO_LINK scenes, plus case-level receipts and source/model fingerprints.

## Scientific stop rules
One field, artificial expert-located gap rectangles, observed seismic pixels preserved under mask erasure, no natural fault-instance negative truth, and repeated CAL inspection mean even a nonzero descriptive result is **not** prospective generalization. If OOF has too few correctly reconstructed TRAIN paths for a gate, STOP with a negative receipt; do not lower thresholds or add TEST labels. Even zero CAL mistakes on 60 potentially correlated source sections cannot certify population geological safety. External TEST7 remains unopened.
