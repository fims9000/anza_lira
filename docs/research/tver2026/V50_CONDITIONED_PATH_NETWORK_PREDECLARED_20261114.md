# V50: Source-conditioned learned path decoder (real Thebe) — locked before any V50 metric

**14 November 2026.** All real Thebe REL-CAL VAL1 40..99 outcomes have been inspected repeatedly. This V50 is an **exploratory engineering study, not independent hypothesis confirmation**. A separate VAL1 30..39 mini-holdout was already opened by V48 and may not be used for model/tuning decisions. The official external TEST7 is prohibited.

## Motivation
The coherent original V46 architecture on one Thebe field proposes the correct pair in 75/120 LINK worlds and ranks it first in 45/120. V47 actual straight and maximin path decoders recover only 2/120 and 0/120 hidden 12-pixel centerlines at 2-pixel tolerance, respectively. Executed V49 observed-boundary straight / Hermite path decoders recover only 3/120 each while retaining 45/120 correct pairs; 0 paths are accepted under the fixed original simultaneous conditional CP gate. Changing simple interpolation geometry is not enough.

## Architectural change
Keep ANZA's verified original V33 trained 2D frontend, V43 q=.70 fallback on dense predicted masks, V40 paired-difference ranking fit on the q70 TRAIN1 candidate population, and V45 five-fold source-section OOF scene-level selective accept/refuse gate unchanged. Introduce a **new explicitly trained source-and-target-conditioned pixel path decoder**, replacing hand-coded geometry for path inference.

Input features use ONLY observation at test time: 48×48 subpatch of original normalized real seismic grayscale (the study's grayscale is NOT erased), observed post-intervention ANZA segmentation probability (ZERO inside synthetic gap), binary known intervention rectangle, Gaussian predicted SBPP source and target markers, a Gaussian predicted endpoint chord prior, and normalized magnitude of seismic gradient. These 7 channels never include the hidden annotated centerline, true endpoints, candidate y label, source section ID or external TEST7.

The decoder has an approximately 40k-parameter residual/dilated small CNN with 16 feature channels, fixed normalization, 25 TRAIN-only AdamW epochs (lr=0.001, weight_decay=0.0001), batch=16, Adam seed 20261114. Training positives are exactly one prediction-derived 8px-correct candidate per controlled TRAIN1 LINK gap if one exists (the highest geometry among true predicted pairs); negatives use the highest-geometry wrong candidate from the same TRAIN1 LINK gap where available. No synthetic NO_LINK is added here; this is path-shape learning conditional on supplied candidate pair, NOT gate learning. Expert hidden centerline is used ONLY as a TRAIN target with a one-pixel expanded line mask INSIDE the known gap, never inference. Train BCE on ROI gap pixels with fixed positive class weight and positive-only soft Dice. No augmentation beyond deterministic horizontal/vertical flips, no CAL loss weighting or checkpoint selection. The final epoch is used regardless of CAL.

A deterministic **oriented ribbon dynamic-programming decoder** traces the maximum aggregate learned path evidence through a bounded corridor joining two automatically derived predicted candidate anchors. It maximizes calibrated neural pixel support minus first-order lateral deviation penalty, along fixed uniform chord sampling. Endpoint anchors come from the original candidate geometry and V49 observed boundary anchor search only; the path builder never reads expert truth. If no anchors are found, it falls back to candidate endpoints. The entire inference and path choice is label-blind.

## Scientific limits
The model is trained on REAL seismic grayscale and expert centerlines from Thebe TRAIN1, but gaps are artificially erased from **the predicted probability**, not from seismic grayscale. Therefore the head can legitimately exploit still-observed seismic intensity within the synthetic missing interval; it must not be described as reconstructing entirely absent image pixels. The gap rectangle is expert chosen, not autonomously detected. All 120 CAL examples are from one previously viewed field. No natural geological fault-instance identity, independent-volume replication, or population false-link guarantee is supplied. New performance can only support a prospective new independent test plan.

If V50 fails to improve actual geometry, preserve the negative result and do not broaden the claim. A valid architecture claim needs a new blinded field and link/path labels, not repeated threshold searches on opened CAL.
