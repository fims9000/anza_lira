# Tver V23 — fixed synthetic 2.5D counterfactual link/NO_LINK benchmark
**Frozen 14 November 2026, before first V23 TRAIN/CAL/TEST outcome inspection.** Branch: \`research/tver-v23-paired-3d-counterfactual-2026-11-14\` based on real-data PR #25. This is a **controlled synthetic mechanism experiment**, not trained ANZA-LIRA on geological F3, and not evidence of better fault segmentation against published 3D CNN/Transformer models.

## Question and novelty
Under identical central 2D pixels, identical supplied source/candidate endpoints, and identical geometry, can actual adjacent 2.5D slice information disambiguate **LINK to candidate 0**, **LINK to candidate 1**, and **NO_LINK** without exceeding a frozen false-bridge budget under OOD? Does this survive distractor stripes, longitudinal deformation, noise, and small image-registration error? V15/V16 established counterfactual 3D gains but failed two-lobed OOD safety; V17–V22 established real-seismic gradient information but not trained ANZA-LIRA E2E. These limitations motivate a new fixed evaluation, not retroactive tuning.

## Controlled 3D world generator
- One base index defines nuisance geometry (2D source + two candidate arms), ridge widths/amplitudes, texture and entire background/noise RNG. For **each base** generate exactly 3 counterfactual worlds with **bitwise identical central 2D image and all geometry/endpoints**, where only near slices change. Link world 0/1 selects which candidate is physically continued by the left source strand; NO_LINK severs both 3D matchings by changing right-branch z-displacement while keeping the central image unchanged. Explicit instance correspondence comes only from synthetic generator; not inferred from CRACKS annotations. Candidate order is hashed by **base ID, independent of latent world**, so index position cannot reveal label. All 3 worlds of a base stay within the same split.
- Render 64×64 real-valued edge/ridge images from four 2D arms with subpixel Gaussian profiles and spatially structured noisy textures, z=−1,0,+1. The central image is independently rendered ONCE per base and copied exactly to the three worlds; near images are re-rendered with z-conditional shifts. Scoring receives supplied source and both candidate 2D endpoint locations, no hidden world ID or synthetic 3D correspondence, and access to images only.
- Fixed frozen base-group split seeds and sizes: TRAIN 200 bases (600 worlds); CAL 100 bases (300 worlds); IID TEST 160 bases (480 worlds); OOD TEST 160 bases (480 worlds). Train/CAL/test seeds are disjoint and base groups never cross partitions.
- In IID, path z-shifts from a smooth central bimodal crossing; OOD uses 50% triangular deformation and 50% two-lobed deformation, higher independent stripe clutter/noise, 1–3px adjacent registration shifts and broad ridge amplitude change. These are **synthetic assumptions**, not natural fault statistics. A separate far-slice sham is pure unrelated nuisance at the same marginal intensity distribution.
- No use of TEST data/labels for selecting features, model family, thresholds, or geometry. Generate/train/calibrate in that order; only open TEST after parameters and decision thresholds frozen. The code must assert central image equality across the entire 3-world group and paired label counts.

## Compared methods
1. **Geometry only**: same 2D source geometry, endpoint direction and distance, no hidden world variables.
2. **Central gradient**: same measured central image and candidate-specific straight-path intensity score. Central-only features cannot theoretically separate the 3 counterfactual worlds as central pixels and geometry match exactly.
3. **2.5D adjacent mean baseline**: per-candidate average straight-path evidence in z=−1/+1, no path registration.
4. **Distant sham**: replace actual adjacent with independent matched-marginal far images. Detects spurious generator-induced labels/normalization artifacts.
5. **V23 source-conditioned 2.5D bridge matcher**: for each candidate and both real adjacent slices, search over possible 3D z-displacements and continuity-compatible source/right traces using only observed near pixel intensities; combine two-neighbor evidence and require a positive source/target *shared track*, not just candidate gradients. No oracle hidden path, latent world, label, or edge-instance identifier at scoring.
6. **Learned gradient boosted trees** on exactly same observed fixed central/near feature family, trained only on TRAIN 600 worlds; a learned 2D-only model on matched center features; a learned 2.5D model with context/bridge evidence; fair prospective calibration on CAL. Optionally include a 2D and 2.5D small CNN if feasible, but never assert comparison without actually running it. Report all methods and no model-family cherry-picking after opening test.

## Frozen decision and statistical rule
- For each policy, compute candidate scores and an evidence magnitude. Choose 0/1 only if: (a) best score exceeds a single model-specific CAL-only acceptance threshold; and (b) score margin exceeds a CAL-only confidence threshold. Else abstain \`NO_LINK\`.
- Select thresholds by exhaustive finite grid over **CAL scores only** maximizing correctly accepted positive scenes subject to empirical false-bridge acceptance ≤2% on CAL NO_LINK and wrong-branch acceptance ≤1% on CAL positives. If no admissible settings accept positives, choose never-link. Thresholds **never** updated after TEST; CAL empirical risk is not a statistical future safety guarantee.
- Primary endpoints reported separately on **untouched IID and OOD**: true-positive correct accepted / positive worlds, false accepted / NO_LINK worlds, wrong candidate accepted / positive worlds, rejection rate, conditional branch accuracy, 3-way exact accuracy and per-world confusion matrix. 160 independent base groups per TEST, each containing 3 dependent worlds. Cluster bootstrap **by base group** (not individual worlds), 3000 resamples, seed 20261114; report 95% CI of paired correctness differences, including against full 2.5D HGB and geometry.
- OOD pass criteria fixed before TEST: false accepted ≤2%, wrong-branch accepted ≤1%, correct accepted hard positive rate ≥15%, and bootstrap lower bound on paired gain over the best **same-information** learned 2.5D baseline >0 (if claiming superiority). Failure is preserved; do not relax criteria or select a successful OOD subgroup.
- Because central observations are identical for all three worlds, central-only three-way correctness averaged over a complete world triplet should be exactly 1/3 for any deterministic policy. This property must have a dedicated unit test. Its weakness is a **benchmark identifiability feature**, not proof a published CNN is inadequate for other seismic tasks.

## Limits and reproducibility
This models **oracle source/endpoint proposals**, artificial line ridges and made-up z-shift kinematics, *not* trained segmentation, candidate detection, true seismic wave physics, or real geological fault identity. V23 correct links cannot be called ANZA-LIRA full-pipeline success. We must report that 2.5D models have more information than 2D models and attribute any gain to **new evidence**, not necessarily a new architecture. No explicit 2.5D gain over equally informed HGB means no model superiority claim. Independent geological-domain evaluation still requires original ANZA/SBPP/LIRA checkpoints and instance-identity ground truth, neither currently present in PR #25.
