# Tver V25: fair equal-hard-negative training for 2.5D learned baselines
**Frozen 14 November 2026 BEFORE any V25 TRAIN/CAL/TEST model outcome was generated or inspected.** Designed AFTER V24 showed that a fixed cross-slice consensus rule outperforms **HGB trained only on earlier easy NO_LINKs**. This is a follow-up, not independent geological validation.

## Mandatory falsification
Do learned models with the **same hard switched-neighbor NO_LINK training worlds** match or outperform the new V24 two-neighbor minimum-consensus verifier? The V24 contrast (+13.54 pp vs HGB) is an *unseen-difficulty OOD inductive bias* result, not evidence of intrinsic general architecture advantage until equal-hard-negative learning is assessed.

## Data and fully independent groups
- Use the EXACT original V24 mechanism: 3 counterfactual worlds per base, central 64×64 image/geometry bitwise identical, positives link to candidate0/1 coherently in z±1, NO_LINK is a hybrid with z−1 exactly a positive world's image and z+1 exactly the opposite positive world's image. All z-wise nuisance, registration ±2.4px, clutter, amplitude and candidate order are paired within each base.
- **New disjoint nuisance base ranges** (not V23/24): TRAIN 200 at **202683010**, CAL 100 at **202693010**, IID TEST 160 at **202703010**. These split ranges are frozen before opening any outputs. All 3 worlds of a base remain in the same split. TEST images and labels are never rendered before all model parameters, preprocessing statistics and acceptance thresholds have been frozen.
- Original TRAIN/CAL from V23/V24 cannot be used in V25 training/validation. No tuning on V24 inspected TEST except the preregistered fixed method choice.

## Equal-information/selective-risk comparisons
1. Frozen analytic **V23 mean-of-neighbor** source-conditioned matcher (no weights) — re-calibrate on *new* hard CAL.
2. New analytic **V24 minimum-of-neighbor** source-conditioned matcher — re-calibrate on *same* hard CAL.
3. **2.5D HGB** (HistGradientBoostingClassifier: learning_rate=.045, max_iter=130, max_leaf_nodes=11, min_samples_leaf=12, l2_regularization=8, random_state=20261114) trained only on **V25 hard TRAIN 600 worlds** using same measured central and adjacent per-source features as both analytic matchers.
4. **2D HGB** on central features alone, same supervised label budget; because each matched base contains all 3 labels with identical 2D images, its maximum deterministic 3-way accuracy on complete groups is exactly 1/3.
5. **2.5D CNN**, a deliberately modest but real trainable raw-image reference (not published FaultSeg3D): input real-valued 64×64 z−1,z0,z+1 observed synthetic layers, plus 3 rasterized source/candidate0/candidate1 visible-coordinate markers. Three 2D conv blocks [16,32,48], kernel sizes 5,3,3 with ReLU and 2×2 average pooling, 8×8 flatten, linear 96→3 outputs. AdamW lr=.001 weight_decay=.01 for **12 epochs**, batch 48, cross entropy, **two independent fixed PyTorch initialization seeds 11 and 23**. CPU one-thread mode. Normalize raw 3 image layers using only TRAIN mean/std and keep visible markers unnormalized. No test-based early stopping or epoch selection. Each CNN predicts two link scores p0−p_NO_LINK and p1−p_NO_LINK.
6. **2D CNN** with the same architecture/training budget but central image repeated in z channels, same visible marker coordinates; it must remain a 1/3-accuracy negative control. If runtime is an issue, report a genuine STOP rather than claiming a CNN was run.

For every method, derive only CAL-based two scalar acceptance thresholds (best-link score and candidate margin) by predeclared finite grid search maximizing correct accepted positives subject to **≤2% empirical NO_LINK false accepts** and **≤1% wrong branch accepted** on 100 CAL base groups (200 positive, 100 NO_LINK). Never pick a promising seed or method using TEST. Compare all two CNN seeds separately plus their descriptive mean; count **160** independent TEST base groups, not 480 independent scenes or 320 independent sample pairs.

## Primary TEST and safeguards
- Full test label distribution: 160 each candidate0, candidate1 and NO_LINK, for **480** choices. Report correct accepted /320 positives, wrong branch accepted /320, false accepted /160 NO_LINK, three-way exact accuracy, CAL thresholds and rejection rate, plus paired **160-base** bootstrap delta with 3000 reps and seed 20261114 for analytic consensus versus each trained baseline and V23 mean.
- On V25 TEST, the per-scene negative should still match exact one-neighbor pixel hashes of opposite positives; central must be bitwise equal. Recompute all reported decisions and losses from case-level CSV independently of the model.
- **Superiority to learned models allowed only if** V24 consensus exceeds the *best of both full-information 2.5D HGB and both raw-image CNN seeds* by a **positive 95% whole-base paired-bootstrap lower bound**, and meets prospective NO_LINK false acceptance ≤2%, wrong branch ≤1%, correct accepted ≥15%. Even then phrase as **"this controlled synthetic benchmark, with available oracle endpoints and hand-crafted track continuity prior"**, never ANZA–LIRA SOTA.
- No checkpoints/weights from historical ANZA/SBPP/LIRA are available in repository. V25 studies a proposed LIRA-like verification component only. It is not a seismic image segmentation benchmark and synthetic labels are not naturally expert-audited geological fault-instance identities.
