# Resume point: CCTA Graph-LIRA Safe Repair

Active Git branch: `research/ccta-graph-lira-safe-repair`

## Canonical current state

Primary anatomy benchmark: ImageCAS-X 800-case bundle, official patient split 560/80/160.

Primary geometry-only stress protocol: 30 deg tangent perturbation + 1 mm endpoint jitter; secondary harder check 45 deg + 1 mm.

Primary current local/structural model:

1. proximity candidate generation;
2. pair and junction geometric logistic rankers;
3. scene-level relation-type head (NONE / PAIR / JUNCTION / BOTH), trained on out-of-fold train predictions;
4. structural compatibility / graph decision;
5. perturbation-consistency selective gate;
6. max-min path remains downstream and is not re-evaluated in this graph-only bundle.

## Current strongest broad-dataset facts

- 800 patients, 4,686 annotated junctions, 45 degree-4 junctions.
- test30 pair top-3 candidate recall 99.15%; junction top-3 92.97%.
- base joint geometry system: exact 52.02%, false 12.34%.
- relation-type head: exact 55.46%, false 10.92%.
- paired patient-bootstrap improvement: exact +3.44 pp [1.76, 5.17], false -1.41 pp [-2.79, -0.05].
- relation-type + validation-selected consistency gate 0.60: test30 coverage 74.34%, false among accepted 0.823%; test45 coverage 81.87%, false 0.863%.
- global matching in exploratory multi-event high-recall test30 reduces false scenes from 31.67% greedy to 27.71%, but absolute false risk is still too high.

## Central diagnosis

Candidate recall is not the main bottleneck. Geometry ranks correct hypotheses well but cannot reliably decide whether a valid repair exists. Stable false pair decisions remain.

Do not spend another iteration tuning pair / junction probability thresholds on the current test set.
